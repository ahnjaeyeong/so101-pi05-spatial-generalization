# 04. 실패 원인 분석 — 무엇이 어떤 데이터로 확인됐나

이 문서는 원인 후보마다 ① 측정된 사실 (A), ② 그 사실을 얻은 데이터 종류, ③ 분석 문서가 내린 해석 (C), ④ 확인되지 않은 범위를 나눠 적는다.
대상 모델은 대부분 **d2 020000** (K1–K8, 256편, expert-only) 이고, 일부는 **redbox 20k** (K1–K4, 384편) 이다.

데이터 종류 표기: [in-sample] 학습 판 · [held-out fold] 학습 데이터 안에서 판·위치를 나눈 probe 검증 · [합성] front 영상에 큐브 합성 · [반사실] 영상 편집·state 변경 · [실물] 로봇 rollout.

## 1. Vision Encoder · VLM (SigLIP / Gemma)

### 1-1. 학습 설정 (A)
- 모든 redbox·d2·d4·A0–A2 학습: `freeze_vision_encoder=true`, `train_expert_only=true` → PaliGemma (SigLIP + Gemma) 전체 고정, action expert (693M / 4.14B) 만 학습.
- d2 vs pi05_base 텐서 비교: vision tower 63/63, projector 2/2, Gemma 표본 23/23 **bit 동일** (최대 차 0). action expert 201 중 1 만 동일 → probe 로 읽는 특징 = pi05_base 특징.
- 초기 practice_10/50, cubemark 15k 는 vision 포함 full FT.

### 1-2. 모델 입력 구조 (A, 코드 확인)
- 640×480 → bilinear (antialias 없음) 224×168 → 위아래 28행 패딩 → 224×224.
- 224 입력에서 front 큐브 13×14 px (0.93 패치), 1 cm = 3.74 px (0.27 패치). wrist 큐브 51–72 px (최대 4.4 패치), 1 cm = 17–25 px.
- Laplacian 분산 (선명도): front 161–402, wrist 5.2–6.3 (wrist 가 훨씬 흐림), 포화 0%.

### 2-1. 시각 변화에 대한 행동 민감도 (A, [반사실], d2 020000, T1 128판 × 3 단계, noise 4)

| 1.0 s | **0.10** [0.02, 0.20] | 0.34 | −0.18 [−0.29, −0.07] |

- [in-sample] 같은 프레임 회귀 (S1): 0–1 s 정책 0.10 vs 사람 0.21; 1–2 s 0.47 vs 0.42 (같음); 2–3 s 0.42 vs 0.53.
- F1 해독값 기준 (S5) pan 이득: 0–1 s 정책 0.08 vs 사람 0.24, 1–2 s 0.52 vs 0.52.
- [실물] 학습 범위 안 평가 프레임 153: 정책 기울기 −0.45 (R² 0.03); 범위 밖 150: 0.04.

### 2-2. state 경로 · roll 토큰 (A)
- roll 정규화 QUANTILES (q01 −57.01°, q99 55.16°, 자르기 없음) → 256 구간 (0.438°/구간) → **숫자를 한 자리씩 프롬프트 토큰**으로 → 고정 Gemma → expert 는 prefix KV 만 읽음 (expert 입력에 state 없음).
- 실물 평가에서 범위 밖 토큰: try3 그리퍼 30.6% 가 '−1' 토큰; try3_filt lift 12.6%·wrist_flex 16.0% 가 q99 초과.
- 가리기: roll 숫자 토큰만 가림 (KR) → pan 0.29–0.32°, 집게 끝 0.14–0.19 cm 변화 (거의 0). state 숫자 전체 가림 (KS) → pan 32–37°, 집게 끝 ~17 cm.
- roll state 를 Δ 바꾸면 roll 행동도 Δ 만큼 (복사 0.97–1.00) → state 숫자는 읽지만 위치 매핑 회전에는 쓰지 않음.
- 주의 질량: 행동 토큰 → roll 숫자 토큰 몫 0.006–0.014.

## 3. Shoulder Pan — 초기 방향 · K 끌림 · 정지

### 3-1. 출발 방향을 무엇이 정하나 (A, [in-sample] + 영상 교체)
- front 영상만 다른 판 것으로 바꾸면 첫 chunk pan 이 그 판 쪽으로 0.59; wrist 만 −0.04; 둘 다 0.67 → **출발 방향은 front 영상이 정함**, wrist·state 는 거의 안 씀.
- 단계별 front 이득: 시작 0.85, 중간 0.040, 파지 직전 0.006.

### 3-2. 새 위치 방향 오차 · K 끌림 (A)

|---|---|---|
| 합성 격자 전체 예측 | 0.46·기대 + 2.4, \|오차\| 중앙 14.4°, 오른쪽 48% | [합성] (타당성 r 0.952) |

- 해석 (C): K 끌림은 새 위치에만 있는 현상이 아니라 학습한 Random 위치에서도 같은 크기다. 오차 부호는 가까운 K·중앙 쪽을 따른다 ("항상 오른쪽" 아님, 48%).
- 충돌: 실물 10-26 5판은 pan 잔차가 모두 + (로봇 오른쪽) 이었다 (+0.4 … +52°). 합성 격자 (48% 오른쪽) 와 데이터가 다르다.

### 3-3. 첫 chunk pan 회전 부족 · 정지 (A)
- 사람: pan 은 첫 움직임에서 총회전의 98%, t90 0.8 s (p95 2.61, 최대 4.33 s).
