# 10. 미확인 · 누락 · 추가 확인 필요 목록

조사 중 근거 파일을 찾지 못했거나, 설정·결과가 확인되지 않았거나, 출처끼리 충돌한 항목이다.
"확인 방법" 은 연구자 확인이 필요한지, 기존 파일을 더 읽으면 되는지 구분했다.

## E. 이 조사 자체의 한계
- 영역별 조사는 하위 조사 에이전트 5개가 원본을 읽고 노트를 만든 뒤 (부록_조사노트) 그것을 합쳤다. 수치는 노트와 원본 파일에서 옮겼고, 일부 핵심 값 (학습 설정, 체크포인트 목록, 학습 시각, q02 완료, 새 OFF 문서) 은 직접 다시 확인했다. 모든 수치를 원본과 1:1 대조하지는 않았다.
- 부록 survey_5 노트는 16:1x 시점 기준이라 q02 "진행 중", HIL "정의 없음" 으로 적혀 있다. 01–10 문서는 16:37 완료본으로 고쳤다.
- 영상 (review_videos, rollout 영상) 은 보지 않았다 (시작 사진 몇 장은 하위 조사에서 육안 확인, C 로 표시).
- io-capture SUMMARY, Ros2 트윈 (e0_j0 상세), Thor 사이트 데이터는 범위 밖으로 두었다.
