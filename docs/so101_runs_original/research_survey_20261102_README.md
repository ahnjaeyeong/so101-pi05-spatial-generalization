## 신뢰도 표기 (모든 문서 공통)

| 기호 | 뜻 |
|---|---|
| **A** | 로그·CSV·JSON·스크립트 출력 등 파일에 남은 측정값. 사람이 UI 로 누른 P/F 판정이 파일에 기록된 경우도 A 로 쓰되 "(사람 판정)" 을 붙임 |
| **B** | 연구자가 실물 로봇에서 본 관찰 (plan.csv 메모, notes, docs 의 사용자 평가 문장, 또는 Claude 메모리에 남은 사용자 발언) |
| **C** | 분석 결과에 근거한 원인 가설·해석 |
| **D** | 앞으로 할 계획 / 설계만 있고 실행 안 됨 |
| 미확인 | 근거 파일을 찾지 못함 |

데이터 종류도 구분해 적었다:
- **[학습 데이터, in-sample]** = 그 모델이 학습한 에피소드 위에서 계산
- **[held-out fold]** = 학습 데이터 안에서 에피소드·위치를 나눠 probe 만 따로 검증 (정책 자체는 전부 학습함)
- **[합성/반사실]** = 영상 편집·큐브 합성·state 바꾸기로 만든 관측
- **[실물 rollout]** = 로봇에서 정책이 만든 상태
- **진짜 held-out 시연 (정책이 안 본 사람 시연)** 은 이 연구 전체에서 **아직 없다** (H 세트는 계획만).
