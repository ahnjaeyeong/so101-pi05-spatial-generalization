## 0. 이 자료를 읽는 규칙 (보고서 작성 시 지켜야 할 것)

1. **신뢰도 기호**: A = 로그·CSV·JSON 측정값 / A(사) = 사람이 UI 로 누른 판정이 파일에 기록됨 / B = 연구자 실물 관찰 (메모·발언) / C = 분석 가설·해석 / D = 계획·설계만.
2. **데이터 종류를 섞지 말 것**: [in-sample] 학습한 에피소드 위 · [held-out fold] 학습 데이터 안에서 판·위치를 나눈 probe 검증 (정책 자체는 그 판도 학습함) · [합성] front 영상에 큐브 합성 · [반사실] 영상 편집·state 변경 · [실물] 로봇 rollout.
3. **정책이 보지 않은 사람 시연 (진짜 held-out) 은 이 연구에 아직 없다.** 계획된 H 세트는 녹화되지 않았다.
4. **오프라인 probe·합성 격자 결과는 실물 성공률이 아니다.**
5. 서로 다른 시스템 두 개가 있다: **redbox (K1–K4, 옛 카메라, 384편)** 와 **d2 (K1–K8, 새 카메라, 256편)**. 겹치는 데이터가 없고 각각 pi05_base 에서 학습했다. 같은 조건 비교는 없다.

## 8. 보고서에서 쓰면 안 되는 표현 (근거 없음)
- "Vision 에는 문제가 없다" → "고정 vision 의 wrist 특징에는 큐브 상대 위치가 정확히 있다 (학습 데이터 held-out fold 기준)" 까지만.
- "HIL 을 적용했다 / HIL 실험 결과" → HIL 은 정의·비교·제안 (2차 방안) 뿐, 실행된 HIL 실험 없음.
- "RTC 가 방향 지속의 원인" / "필터가 −109° 이탈의 원인" → 재구성 결과 둘 다 주원인 아님 (필터 끔 B1 도 같은 이탈).
- "재표집은 효과가 없다" → "A1 (구간 가중) 은 오프라인 대리 지표에서 개선이 없었다; A2·A2r 미평가, 로봇 평가 없음".
- "d2 (256편) 실물 성공률 X%" 를 10-26 근거로 → 10-26 판정 없음.
- "큐브 회전이 실패 원인" → 데이터상 시작 각도는 무관.
- "필터가 성공률을 높인다/낮춘다" → A/B 40판 차이 없음, K1 4+4 는 혼란변수로 구분 불가.
- "나무 큐브" → 재질 기록 없음 (연구자 확인 필요).
- "held-out 평가" → 진짜 held-out 시연 없음 (H 미녹화).
