## [해석] (자체 실험, n = 5 — 일반화할 수 없는 규모)

- **가장 뚜렷한 차이는 초기 pan 회전 속도다.**
  - 정책이 필요한 pan 회전의 90% 를 채운 시간: 2.2 / 2.8 / 6.1 / 14.6 s (1판은 90% 에 못 미침). 사람은 중앙값 0.8 s, 95% 2.6 s, 최대 4.3 s 다.
  - 정책의 첫 하위 움직임은 1–19° 로, 필요 회전 (22–58°) 의 일부만 덮는다. 사람은 98% 를 한 번에 덮는다.
  - 접근 시간도 12–28 s 로, 사람 중앙값 8.3 s · 최대 16.3 s 보다 길다.
- **이탈 시점:** 정책 상태 (pan 오차, 반지름, 높이, 진행률) 가 사람 분포 99% 밖으로 처음 나간 시각과 원인은 판마다 다르다.

  | 판 | 이탈 시각 (onset 뒤) | 이탈 원인 | 사람 기준 |
  |---|---|---|---|
  | try3 ep0 | 3.6 s | 진행률 19% 에서 pan 오차 11.5° | 같은 진행률 사람 |pan 오차| 95% = 6.8° |
  | filt ep1 (새 위치) | 8.2 s | 진행률 30% 에서 pan 오차 −13.6° | |
  | try3 ep1 | 11.1 s | 첫 닫힘 1.3 s 전 pan 오차 7.6° | |
  | filt ep2 | 0 s | 시작 TCP 높이 (−1.0 cm) | 사람 0.3 ± 0.4 cm |
  | filt ep0 | 이탈 없음 | | |

  pan 오차로 이탈한 3판에서는 **pan 이 덜 돌아간 채 접근이 진행된 상태**가 먼저 나타났다.
- **새 위치 1판 (filt ep1)** 은 첫 닫힘 때 pan 오차 +10.2° (로봇 오른쪽), e_t −5.9 cm 로, 사람 파지 순간 범위 (|pan 오차| 95% 4.8°, |e_t| 95% 1.25 cm) 의 2–5배였다. 이 판은 프레임의 65% 가 사람 분포 밖이었다.
- 평가 wrist 라벨 프레임 (닫힘 3 s 안) 의 42% 가 사람 |tan| 범위 밖이고, roll 조건 없이 tan · rad 만 맞춰도 41% 는 이웃 시연이 0이다. 실패 상태는 'roll × 오차 조합' 이전에 **오차 크기 자체가 학습 범위 밖** 인 경우가 많다.

## [가설]

- '정책이 pan 을 천천히 · 덜 돌린 채 접근 → 사람 시연에 없는 중간 상태 → 그 상태에서의 보정 시연이 없음' 이 연쇄로 이어질 수 있다. 사람 시연의 pan 회전 구간은 판당 ~19 프레임이고, 큰 접선 오차 보정 시연은 15–37편뿐이다 (05 문서).
- 정책이 오른쪽으로 치우친다는 이전 관찰 (diag_grasp_bias: pan +5…+12°) 과 사람의 늦은 오른쪽 pan 이동 (69%, 05 문서) 은 방향이 같다. 관련이 있는지는 확인하지 않았다.
- 실행 경로 (RTC h20 · steps 5 · arm_filter · max_relative_target 8) 가 pan 회전을 느리게 만드는 몫은 이 자료로 분리할 수 없다. diag_grasp_bias 는 필터 · 클램프 · 추종 영향이 ≈ 0 이고 drift 가 모델 자체 재계획이라고 보고했다 (그 보고서의 결론이며 이번에 재검증하지 않음).

## 불가능했던 분석과 이유

- 성공/실패 판정이 기록되지 않았다 (평가_명령.md). 첫 닫힘 뒤 그리퍼 값으로 '무언가 쥠' 만 추정했다.
- d2 정식 평가 (eval_ui) 가 없어, 새 위치 판이 1판뿐이다. '새 위치 첫 접근이 실패하기 시작하는 상태' 를 일반화하려면 위치 라벨이 있는 평가 판이 더 필요하다.
- main/redbox_all 의 80판 정책 평가 (이전 카메라 · K1–K4) 는 학습 데이터 · 카메라가 달라서 합치지 않았다.
