# 05 재계획 (새 관측 → 새 chunk) 과 chunk 경계의 Pan (기존 실물 5 판)

작성 2026-10-29. 생성 스크립트: `scripts/p01_timeline.py`, `p03b_guided_recon.py` (GPU), `p03c_counterfactual.py` (GPU), `p06b_raw_vs_rtc.py`, `p06c_focus_cases.py`, `p06d_counterfactual_summary.py`, `p06e_case_abcd.py`. 그림 `figs/fig3_raw_vs_rtc_focus.png`, `figs/fig4_seam_counterfactual.png`.

값의 종류:
- **[실측]** = 당시 기록된 실행 명령 (queue 출력, 필터 전) · state.
- **[재구성]** = 기록된 dataset 프레임 · state 를 정책에 다시 넣은 오프라인 계산.
  - U = RTC 안내 없음 (prefix 없음).
  - G = RTC 안내 있음. 같은 noise, prefix = 앞 chunk index 20–39, inference_delay = 코드 규칙값.
  - G 의 prefix 중 index 0–9 (추론 동안 실행된 앞 chunk index 20–29) 는 기록값이다. index 10–19 (앞 chunk index 30–39) 는 실행 · 기록되지 않았으므로 추정해야 한다. `p03b` 는 앞 chunk 재구성으로, `p03c` 는 hold (마지막 실행값 고정) · lin (마지막 5 index 기울기 연장) 로 채웠다.
- **[반사실]** = 기록 당시와 다른 조건 (inference_delay 등) 을 넣은 오프라인 계산. 실물에 적용하지 않았다.

## 1. chunk 구조 (02 문서 요약, [실측] · [코드])

- 새 chunk 는 merge 간격 p50 0.669 s 마다 들어왔다. 추론 지연 p50 0.34 s, 적용 delay 10 틱 (304 번 중 266 번).
- chunk k ≥ 1 은 index ≈ 10–29 가 실행됐다. 새 chunk index j 는 앞 chunk index 20 + j 와 같은 시각이다.
- RTC 안내 weight (EXP, h 20) 는 inference_delay d 에 따라 다르다.
  - d = 11: index 10 → 1.0 · 12 → 0.57 · 14 → 0.29 · 16 → 0.11 · 18 → 0.03 · ≥ 20 → 0.
  - d = 0: index 10 → 0.17 · 15 → 0.04.
  - 실행 구간 index 20–29 에는 어느 경우에도 안내가 없다.
- d = 0 은 실행 (세션) 의 두 번째 추론에서 나온다 (첫 추론 뒤 LatencyTracker reset). 5 판 중 해당 chunk 는 try3/ep0 chunk 1 과 filt/ep0 chunk 1 이다.

## 6. 측정 사실 요약

1. 같은 관측 · noise 에서 RTC 안내가 실행 끝 index 의 pan 을 바꾼 양은 중앙 0.3° 다 [재구성]. 1 s 이동 비율도 U · G 가 거의 같다 (fU 중앙 0.18, fG 0.17).
2. 세 역전 사례 모두 안내 없는 U 에서 같은 방향의 끊김이 나타난다 (중앙 −4.4 … −17.3°) [재구성].
3. 기록 당시 inference_delay 0 이었던 filt/ep0 chunk 1 은 안내 weight 가 실행 첫 index 에서 0.17 이다 [코드]. 같은 noise · 관측에서 d = 11 이면 경계 끊김 p10–p90 이 ±2.6° 안으로 준다 [반사실].
4. inference_delay 11–12 인 chunk 에서 안내는 경계를 잇는다. 하지만 안내가 끝나는 index 20 이후 실행 구간에서 목표 반대쪽 10° 이상 되돌아가는 noise 가 19–34 % 다 [재구성 · 반사실].
5. A/B/C/D 분류에서 C (서보) 0 건, B (RTC 가 줄임) 2 건, A · D (모델 계획) 45 건이다 (임의 문턱).

## 7. 한계

- 당시 noise 와 실제 관측 영상이 기록되지 않았다. 재구성은 '같은 관측에서 가능한 출력의 분포' 이고 당시 출력이 아니다. 기록값이 재구성 p10–p90 에 든 비율 (65–70 %) 은 기대치 80 % 보다 낮다.
- G 재구성의 prefix index 10–19 는 기록이 없어 가정 (est · hold · lin) 에 따라 값이 달라진다 (filt/ep2 c1 에서 est 와 hold 의 seam 중앙 차 15°).
- 관측 틱은 merge 틱 − 적용 delay 로 근사했다 (±1 틱).
- A/B/C/D 문턱 (0.25, 0.15, 0.5) 은 임의 값이다.
- 반사실 (d = 11, RTC 끔) 은 열린 고리 (한 chunk) 계산이다. 실물 닫힌 고리에서 다음 관측 · 다음 chunk 가 어떻게 바뀌는지는 계산하지 않았다.
