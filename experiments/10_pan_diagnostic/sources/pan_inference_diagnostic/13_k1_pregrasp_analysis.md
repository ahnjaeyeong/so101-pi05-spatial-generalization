- 필터가 바꾼 명령은 닫힘 직전 관절별 중앙 0.4° 이하다. 닫힘 순간 '명령 대비 팔 위치' 와 FK 상대 높이는 켬 · 끔이 같은 범위다.
- 그리퍼는 필터를 거치지 않는다. 켬에서 그리퍼 명령 → 실제 닫힘 시작이 더 길었던 것 (4–15 틱 vs 3 틱) 은 그리퍼 명령 곡선 모양의 차이다. 필터와의 인과는 확인할 수 없다.
- 사용자가 본 '켬에서 파지 직전 좌우로 벗어남' 과 같은 방향의 측정값이 있다: 손목 화면 가로 변화폭이 켬 중앙 0.084, 끔 0.042 다.
  - pan 실제 변화폭은 비슷했다 (1.4° vs 1.1°). wrist_roll 실제 변화폭은 켬이 더 컸다 (0.9–3.7° vs 0.1–2.1°).
  - 큐브 각도도 켬이 컸다 (+31° · −45°). 필터 때문인지는 구분 불가다.

## 4. 손목 영상 vs FK (분리)

- **손목 영상 (직접 관측, dataset 영상):** 큐브 중심 u · v · 넓이 · 테두리 걸림. '앞쪽 / 사람 범위 안 / 아래쪽 가장자리' 와 좌우를 사람 5–95 % 범위로 판정했다. 깊이는 화면 세로 위치 (v) 로만 본 것이다. 3 차원 깊이 · 접촉은 아니다.
- **FK (ac.tcp):** K1 성공 5 번 모두 TCP 가 사진 좌표 큐브보다 로봇 오른쪽 3.9–5.4 cm 로 나온다. 같은 순간 손목 화면은 중앙이었다. 이 자세에서 FK 절대 위치는 틀린다. FK 는 같은 순간 '명령 vs 현재' 의 상대 차로만 썼다.
