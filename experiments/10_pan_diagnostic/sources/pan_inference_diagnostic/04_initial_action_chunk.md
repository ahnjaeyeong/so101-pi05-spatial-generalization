# 04 판 첫 action chunk 의 Pan (기존 실물 5 판)

작성 2026-10-29. 정책 d2 020000. 생성 스크립트: `scripts/p02_existing_metrics.py`, `p03b_guided_recon.py` (GPU), `p03c_counterfactual.py` (GPU), `p06b_raw_vs_rtc.py`, `p06c_focus_cases.py`, `p06d_counterfactual_summary.py`. 그림 `figs/fig3_raw_vs_rtc_focus.png`, `figs/fig5_chunk0_distribution.png`.

값의 종류를 줄마다 표시한다.
- **[실측]** = 당시 실물 실행에서 기록된 값 (queue 출력 raw = 필터 전 명령, state = Present_Position).
- **[재구성]** = 기록된 dataset 프레임 (AV1 재부호화) · state 를 지금 정책에 다시 넣어 오프라인으로 계산한 값. noise 는 당시 값을 모르므로 고정 은행 (seed 1234 …) 에서 뽑았다. 당시 실물이 낸 값이 아니다.

## 1. 판 첫 chunk 는 RTC 를 거치지 않는다 (코드 · 로그)

- 판 시작 때 queue 를 비우므로 첫 추론에는 prefix (prev_chunk_left_over) 가 없다. RTC 안내 (guidance) 는 prefix 가 있을 때만 걸린다 (02 문서 2 절).
- 첫 chunk 는 queue 가 빈 상태에서 merge 되어 index 0 부터 실행되고, 다음 chunk 가 merge 될 때까지 index 0–29 가 실행됐다 (5 판 모두, `p02_policy_episodes.csv` chunk0_exec_idx).
- 따라서 5 판 첫 chunk 의 index 0–29 기록값은 **Action Expert 출력 (unnormalize 뒤) 그 자체** 다 [실측]. index 30–49 는 실행 · 기록되지 않았다.

관측 = dataset frame 0 (front · wrist · state). 첫 chunk 의 실제 관측 틱은 dataset 에 없다 (03 문서). 판 시작 전 팔이 멈춰 있어 state 는 같다. noise 256 개 (`p03c`, seed 1234–1241 × 32), RTC 없음 (첫 chunk 와 같은 조건).

## 5. 사람 시연과 비교 (1 s 이동 비율)

같은 정의: (1 s 뒤 명령 − 현재 state) / (pe − 현재 state). 사람 = 리더 action t+30 [실측, d2 시연 256 편]. 정책 기록 = 실행 명령 t+30 [실측]. 정책 계획 = 재구성 U[29] (noise 8 개 × 첫 닫힘 전 모든 chunk) [재구성]. (`tables/p06c_summary.json` plan_gain_by_resid)

## 6. 측정 사실 요약

1. 첫 chunk index 0–29 는 RTC · 필터 · clamp 이전의 Action Expert 출력이다 [실측 + 코드]. filt/ep1 의 −7 % (index 29) 는 이 출력의 값이다.
2. 같은 관측에서 첫 chunk 의 1 s pan 은 noise 에 따라 0 에서 need 전체까지 퍼진다 [재구성]. filt/ep1 은 noise 의 54 % 가 10 % 미만이다.
3. 재구성 계획의 이동은 chunk 뒤쪽 (index 30–49, 실행 안 되는 구간) 에 몰려 있다 [재구성].
4. 1 s 계획 이동 비율은 사람 시연보다 작고, 실물 기록과 비슷하다 [재구성 vs 실측].

## 7. 한계

- 재구성 관측은 dataset AV1 재부호화 프레임이고, 첫 chunk 의 실제 관측 틱 · 영상은 기록되지 않았다. 당시 noise 도 기록되지 않았다. 따라서 기록값 하나가 재구성 분포의 어디에 있는지만 말할 수 있고, '당시 그 값이 나온 이유' 는 재현하지 못한다.
- filt/ep2 첫 chunk (기록 frac 0.83, 재구성 256 개 중 위 1 %) 는 관측 차이 (영상 부호화 · 관측 시각) 때문인지 드문 noise 때문인지 구분할 수 없다. 계측 켠 신규 평가 (`07`) 는 정책이 받은 PNG · noise 를 남기고, harness 에서 기록 입력으로 다시 계산한 값이 기록과 정확히 같음을 확인했다 (07 문서 6 절).
- 기준 pe 는 영상 추정 큐브 방위 기반이다 (SD 2.31°). frac 의 분모 오차는 need 가 작을수록 크다.
- 5 판, 한 정책.
