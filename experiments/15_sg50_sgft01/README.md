## 목적
- 손목 카메라가 큐브 (흰 원 스티커) 를 계속 보게 하는 일관된 시연 (고정 시작 자세 · 정해진 진행 순서 · 수직 파지) 을 모으고,
- d2 020000 에서 그 시연으로 파인튜닝했을 때, 정책이 **처음 숄더팬을 front 로**, **그 뒤 다시 맞추기와 닫기를 손목 영상으로** 하는지 오프라인에서 확인.

## 검증 가설
- [가설] 손목 영상에 일관된 정렬 신호 (주황 닫기 프레임) 가 있는 시연으로 학습하면 손목 → 행동 이득이 d2 보다 사람 쪽으로 간다.
- 사전 판정 기준: 없음 (오프라인 비교 지표만 정함 — 아래 평가 방법).

## 수집 (도구 · 결정)
- [사실] 수집 화면 (`tools/sg_viewer.py`, 녹화 프로세스의 /dev/shm 프레임을 읽기만): 위에서 본 탁자 (놓을 자리) · Front (빨간 원 '여기 놓기') · Wrist. 녹화 영상에는 아무것도 그리지 않음.
- [사실] 손목 화면 안내 (모두 참고 표시, 판정 · 자동 동작 없음):
  - 주황 닫기 프레임: 잘 잡은 판의 닫기 순간 큐브 윤곽, 좌우 · 앞뒤 · 크기 · 회전 허용 안이면 위 띠 초록. 활성 ref-v5 = 예비2 ep0 · ep3.
  - 수평계: FK 그리퍼 앞뒤 기울기. 0 점 = −10.47 + 4.16·sin(pan), 사용자가 수직으로 세운 3 자세로 맞춤 (잔차 ≤ 0.2°).
  - 그리퍼 열기 알림: 숄더팬을 돌린 뒤 · 찾기 시작 · 큰 팔 뻗기 때 그리퍼를 안 열었으면 '그리퍼를 열어주세요' 깜빡임.
- [관찰] 사용자 결정 순서 (원문 `13_sg50_sticker.md`):
  - 시작 자세 S0 = 쉬는 자세 + 손목 약 90° 돌림 (11-06).
  - 진행 = 숄더팬 → 그리퍼 열기 → 찾기 → 이동 (11-06 14:19).
  - 사선 31° 시도 (14:24–14:44) 뒤 "손목서보가 90도로 오게" = 수직으로 되돌림.
  - 끝 = S0 로 돌아와 녹화 끝.
  - 결과 입력 (첫 파지 / 재시도) 안 씀.
- [사실] 자리: K1–K8 한 번씩 + K 마다 둘레 칸 (x ± 4.25 · y ± 7.5 cm) 무작위 4 점.
  - 조건: 수직 최대거리 (FK, 28.5 + 1.25·sin(pan) cm, 사용자 실측 정면 28.6 cm) 안 · 평가 전용 자리 ≥ 3.5 cm · 서로 ≥ 2.5 cm.
  - 계획 40 판, 같은 영역 연달아 0.

## 분석 결과
- [사실] in-sample 오차 · 그리퍼 판단은 2500 에서 크게 줄고 7500 ~ 10000 은 비슷. S0 의 손목 회전 (약 90°) 오차 47.5 → 2.9°.
- [사실] d2 판 (C) 오차는 2.24 → 9.49 로 커짐 (손목 회전을 S0 처럼 돌림) — 예비3 만으로 학습.
- [사실] front → 숄더팬 이득은 d2 부터 있었고 1 에 가까워짐. 손목 좌우 → pan 은 방향이 사람과 같아졌으나 크기 약 0.4 배, 앞뒤 · 회전 · 크기 → 해당 관절 반응은 0 근처. 닫기는 큐브가 프레임 밖이어도 줄지 않음.
- [사실] 사람 기준 기울기 (손목 큐브 ↔ 프레임 차이와 사람이 고친 양) 의 상관은 0.12–0.51 로 낮음 (사람 기준 자체가 거침).
- [가설] 40 편 · 같은 자세 · 같은 순서로는 숄더팬 · 순서 · 자세는 배우지만, 손목 화면의 세밀한 정렬 (앞뒤 · 높이 · 회전) 과 정렬 조건 닫기는 배우지 못함 (EXP-08 의 손목 정보 덜 쓰는 행동 부분과 비슷한 모양).

## 한계 및 미확인
- held-out 사람 시연 없음 (B 는 같은 작업자 · 예전 순서). V2/V3 는 영상 변환 [반사실] — 실제 그리퍼 · 큐브 기하와 다를 수 있음.
- 시험 장면 · noise 수 제한 (V2 118 장면 × noise 4). 수평계 FK 보정은 팔을 뻗은 자세로 맞춤 (접은 자세 오차 4–8°, 손목 사진 추정).
- 본 수집 (48 편 계획, `main_k8/sg50_main`) 은 실행 안 함.
