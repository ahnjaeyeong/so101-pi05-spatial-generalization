## 놓는 방법

- 좌표: 탁자 cm. 원점 **C** = 상자 앞(로봇 쪽) 벽 바깥면의 오른쪽 아래 모서리 (0, 0). **x = 앞(상자 쪽, front 화면 위)**, **y = 왼쪽(front 화면 왼쪽)**. 음수 x = 상자 앞 벽에서 로봇 쪽.
- 이 표의 **ep 번호 = lerobot episode 번호**. ← 로 다시 찍으면 같은 번호 → 같은 배치를 다시 놓는다.
- 저장된 판을 버릴 때: `layout_plan.py exclude` → 같은 배치 ID 가 맨 끝에 새 줄로 붙는다 (이어 찍기로 채움).
- 탁자의 K 표시(①–④) 위에 큐브 중심을 맞춘다. 큐브 면은 상자 앞 벽과 나란히. 허용 오차 약 ±0.5 cm.
- 표시를 지웠을 때는 실제 크기 템플릿 `layout_template_a3.svg` (A3 가로, 100% 인쇄): 위쪽 점선을 상자 앞 벽에 맞대고 C 표시를 상자 오른쪽 끝에 맞춘다.
- 위치 그림: `layout_map.svg` (front 화면과 같은 방향)
