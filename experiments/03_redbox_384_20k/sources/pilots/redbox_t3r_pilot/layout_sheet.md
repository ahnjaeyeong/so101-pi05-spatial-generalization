## 놓는 방법

- 좌표: 탁자 cm, 원점과 축은 설정 파일 머리 주석 (카메라 보정과 같은 고정 기준). **x = 앞(상자 쪽, front 화면 위)**, **y = 왼쪽(front 화면 왼쪽)**.
- **C** = 지금 상자 앞(로봇 쪽) 벽 바깥면의 오른쪽 끝 = (0.75, 2.05).
- 이 표의 **ep 번호 = lerobot episode 번호**. ← 로 다시 찍으면 같은 번호 → 같은 배치를 다시 놓는다.
- 저장된 판을 버릴 때: `layout_plan.py exclude` → 같은 배치 ID 가 맨 끝에 새 줄로 붙는다 (이어 찍기로 채움).
- **자유 배치**: 판마다 손으로 놓는다 (빨간 큐브, 파란 큐브, 초록 큐브). 좌표는 미리 정하지 않는다.
- 규칙: K 표시(K1, K2, K3, K4)에서 3 cm 넘게, 물체끼리 8 cm 넘게, 상자 벽에 닿지 않게. 판마다 자리를 바꿔 녹화 화면 안 탁자 전체에 고루 퍼지게.
- 위치는 녹화 뒤 `check_dataset.py` 가 첫 화면에서 역산해 `qa/positions.csv` 에 남기고 규칙 위반 판을 알려 준다.
