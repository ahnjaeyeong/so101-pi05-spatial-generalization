> redbox 384편 (EXP-03) 과 d2 256편은 **겹치는 판이 없는 별도 데이터셋**이고, d2 는 redbox 체크포인트를 이어받지 않고 **pi05_base 에서 새로** 학습했다.

## 목적
- [사실] front 카메라를 상자 쪽 위로 옮기고 고정 위치를 K1–K8 (3줄 격자) 로 바꿔 본 수집 다시 시작. 옮긴 이유는 기록 없음.
- [사실] d1 (T1+T2) / d2 (T1+T3) / d3 (T1+T2+T3) 비교 계획 중 d2 만 실행.

## 검증 가설
- [가설] 명시된 가설 문장 없음. 새 카메라·K1–K8·큐브 각도 계획으로 같은 레시피를 다시 학습하면 위치 일반화가 나아지는지 보는 비교 실험 (d1/d2/d3) 으로 설계됨 (d1·d3 는 T2 미녹화로 실행 안 됨). d4 의 가설 (T3-K 제외) 은 미기록.
