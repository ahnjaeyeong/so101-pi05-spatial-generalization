## 3. 공개 자료에 있는 것 / 없는 것

- 레퍼런스 README·프로젝트 페이지의 π0.5 관련 서술:
  - "frozen (Pi0.5) preserve a competent visual representation"
  - Known-only 학습이 표시 위치에 과적합 (ACT·SmolVLA, D1-K 10/20)
  - visual servoing(손목 영상 기반 막판 교정)에 대한 서술이나 측정은 없다.
- 스펀지 크기·강성: 수치가 없다. 페이지에 "regular cuboidal sponges", "pinch strategy", 시간이 지나 굳은 스펀지 사례가 있다.
- 레퍼런스 모델의 위치 민감도(영상 편집·noise 분산) 측정은 공개 자료에 없다.

## 4. 레퍼런스 모델 위치 민감도 측정 설계 (아직 실행 안 함)

**원칙:** 두 로봇의 카메라 위치·관절 영점이 다르다. 그래서 '도'나 'cm' 를 직접 비교하지 않는다. 각자 자기 사람 시연에서 맞춘 '이상 반응'에 대한 비율(무차원 이득)로만 비교한다.

필요한 것 (d4 학습이 끝난 뒤, 사용자 승인 후):
- 모델 가중치 9.35 GB (`pretrained_model/` 만, optimizer 제외)
- task2 영상 중 고른 판이 든 파일만 (overhead·wrist). 판 목록은 meta/episodes 의 file_index 로 미리 정한다.
- GPU: 우리 exp1–2 와 같은 규모면 약 30–40 분. 학습과 동시에 돌리면 학습이 1.5–2 배 느려진다 (2차 분석 실측).

절차:
1. **로딩·동치 검사:** `probe_core.Engine` 을 레퍼런스 체크포인트용으로 넓힌다. rename_map, empty_cameras, task 문장, denoise step 10 (그들 설정)과 5 (우리 설정) 둘 다.
   - 같은 noise 로 `predict_action_chunk` 와 prefix 재사용 경로가 같은지 확인한다 (우리 0.0 확인과 같은 방법).
   - 영상 순서·mask 가 설치된 lerobot 판에서 학습 때와 같은지도 확인한다.
2. **물체 검출:** 파랑 스펀지 HSV 범위를 그들 overhead·wrist 첫 프레임 몇 장으로 맞춘다. overhead 첫 프레임과 닫힘 직전 wrist 프레임에서 검출률을 보고한다.
3. **이상 반응을 자기 시연으로 맞춤 (탁자 좌표·H 를 쓰지 않음):**
   - front/overhead: 사람 시연 '파지 pan' ~ '첫 프레임 물체 픽셀 (u, v)' 를 국소 회귀한다 (kNN 또는 2차식, 자기 데이터 안에서). 영상에서 물체를 Δpx 옮겼을 때의 이상 Δpan = ∂pan/∂(u,v) · Δpx.
   - wrist: 사람 시연 파지 1–3 s 전 구간에서 Δ(wrist 물체 중심 u, v) ~ Δ관절(pan, lift, elbow, wrist_flex, roll) 를 최소제곱한다 (FK·URDF 를 쓰지 않음 → 캘리브레이션 규약 차를 피함). 영상 이동 Δimg 에 대한 이상 관절 교정 Δq* = J⁺(−Δimg) (판마다, 또는 roll 구간별).
   - 우리 쪽도 같은 방법으로 다시 계산한다. 우리 exp2b 는 FK 를 썼으므로, 비교용으로는 관절공간 방식으로 다시 낸다.
4. **편집·측정:** 우리 exp2 와 같은 단계(start / mid / pre), 같은 편집(물체 지우고 옮겨 붙이기 ± 대칭), 같은 noise 은행(64개 중 4개).
   - 이득 = (Δq_model · Δq*) / |Δq*|². pre 단계는 index 30. pan 성분과 '좌우 성분'(Δq* 방향 중 pan 이 큰 쪽) 따로.
   - 레퍼런스는 n_action_steps 50 으로 운용하므로 index 49 까지 읽는다.
5. **아티팩트 분리:** 우리 실험 5 와 같은 보정 곡선(자기 학습 random 판 start 예측 vs 사람 pan)을 각 모델에 따로 맞춘다. chunk 안에서 덜 돈 정도를 빼고 비교한다.
6. **seed 분산:** 같은 관측에 noise 64개 → start · pre 단계 pan SD (step 10 / 5).
7. **비교 보고:** 무차원 이득(front: start·mid·pre, wrist: pre 좌우·앞뒤), 보정 전후 K/표시 위치 끌림 계수.
   - 그들 fixed 6곳 기준. 표시 6곳의 좌표는 영상에서 구한 픽셀로만 쓴다.
   - 도·cm 단위 값은 나란히 두지 않는다.
