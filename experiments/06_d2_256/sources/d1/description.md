# d1 — T1 + T2 (main_k8)

작성 2026-10-23. main_k8 비교 실험 d1 · d2 · d3 중 하나. **아직 준비 안 됨 — T2 미녹화.**

| 실험 | 학습 데이터 | 상태 |
|---|---|---|
| **d1** | **T1 + T2** | **T2-K · T2-R 녹화 대기 (계획만 있음)** |
| d2 | T1 + T3 | 데이터셋 합침·검증 완료, 학습 스크립트 준비됨 → `../d2/description.md` |
| d3 | T1 + T2 + T3 | T2 미녹화 → `../d3/description.md` |

세 실험 모두 T1 을 공통으로 넣고, 함께 넣는 과제(T2 / T3 / 둘 다)만 바꾼다.

## 1. 과제 정의

| 과제 | 내용 | 학습 문장 (task) |
|---|---|---|
| T1 | 탁자 위 빨강 큐브 1개를 갈색 상자에 넣기. 다른 물체 없음 | `pick up the red cube and put it in the brown box` |
| T2 | 빨강 큐브 2~4개를 모두 상자에 넣기. 다른 물체 없음 | `put all the red cubes in the brown box` |

- 문장이 2개라 d1 데이터셋의 task 는 2개가 된다 (2026-10-22 사용자 결정: 문장 통일 안 함).
- 수집 환경(카메라·K1–K8·각도 정의)은 d2 와 같다 → `../d2/description.md` 2절.

## 2. 들어갈 데이터

| 순서 | 세션 | 상태 (2026-10-23) | 편수 |
|---|---|---|---|
| 1 | `redbox_t1_known` | 완료, 제외 51 · 64 → `release/` 있음 | 64 · 33,974 프레임 |
| 2 | `redbox_t1_random` | 완료, 제외 2 · 36 · 39 · 41 → `release/` 있음 | 64 · 32,758 프레임 |
| 3 | `redbox_t2_known` | 계획만 (seed 2201) | 목표 64 |
| 4 | `redbox_t2_random` | 계획만 (seed 2202) | 목표 64 |

- T1 두 개의 release 사본은 d2 를 만들 때 만든 것을 그대로 쓴다 (만드는 법·확인 결과: `../d2/description.md` 3.1).
- T2 계획 (layout.csv):
  - 빨강 개수: 2개 24판 · 3개 24판 · 4개 16판 (16판마다 6·6·4).
  - T2-K: K 조합을 골고루 뽑음 (K 마다 빨강 23번), 각도 4가지(0 · ↺30 · ↻30 · 45)를 K 마다 골고루.
  - T2-R: 위치 자유, 빨강마다 각도 지정 (예: `T2R01n3` = 빨강 3개).
  - 판 시간 75초 (T1 은 45초).

## 3. 준비 순서 (T2 녹화 뒤)

1. `layout_plan.py train-args --session main_k8/redbox_t2_known` / `..._t2_random` 로 제외 목록 확인.
2. 제외 판이 있으면 그 세션의 `release/` 사본을 만든다 (`--new_root` 필수, 원본 수정 금지).
3. 합침: 순서 T1-K → T1-R → T2-K → T2-R, 경로 `main_k8/d1/dataset`, repo `oxr/so101_k8_d1`.
4. 합친 뒤 판 길이 순서·경계 프레임·task 2개 확인.
5. 학습 스크립트는 d2 와 같은 설정에 데이터셋·출력 경로만 바꿔 `d1/train/` 에 둔다.

## 4. 정하지 않은 것

- 스텝 수: d2 는 20k (bs32). T2 는 판이 더 길어서 d1 의 프레임 수가 d2 와 다를 것이므로, 같은 20k 이면 epoch 가 달라진다.
- 평가 과제·조건·판 수.
