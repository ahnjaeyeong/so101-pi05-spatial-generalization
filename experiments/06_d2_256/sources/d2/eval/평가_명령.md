# d2 실물 시험·평가 명령 (2026-10-26)

- 체크포인트: `train/32_20000/pi05_expert_bs32_20k/checkpoints/020000` (학습 완료 10-26 00:50, 마지막 loss 0.020)
- **둘 다 팔에 토크가 걸리고, 모델 로딩(2–3분)이 끝나면 바로 움직인다.** 직접 실행.
- 추론 설정은 두 명령 모두 같게 둔다 (redbox_all eval_ab · eval_space 와 같은 값):
  RTC, execution_horizon 20, prefix_attention_schedule EXP, num_inference_steps 5, queue_threshold 30.
- **팔 필터 켬** (2026-10-26 사용자): `--arm_filter=true` = 팔 5관절 EMA α 0.5 + 관절별 속도 제한, 그리퍼 제외 (`arm_filter.py`).
  두 명령 모두 이 폴더의 `rollout_logged.py` · `arm_filter.py` 를 쓰므로 같은 필터. 실행 폴더에 `filter_log.csv` (필터 전·후 action·실제 상태), dataset action = 필터 후 값.
  - 참고: 10-26 13:51 첫 시험 `rollouts/20261026_135128_20k_t1_try3` 는 필터 없이 돌린 것.
- 과제 문장은 T1 · T3 모두 `pick up the red cube and put it in the brown box` (학습과 같음). T1/T3 구분은 tag 이름으로만 한다.

## 1. 시험 3판 — run_rollout.sh (녹화 + 자동 분석·그래프)

```bash
cd ~/so101_runs/main_k8/d2/eval
TASK=t1 N_EP=3 ./run_rollout.sh try3_filt \
  --inference.type=rtc --inference.rtc.execution_horizon=20 --inference.rtc.prefix_attention_schedule=EXP \
  --policy.num_inference_steps=5 --inference.queue_threshold=30 --arm_filter=true
```

- 키: n/→ = 이 판(또는 리셋) 끝내고 다음 · r/← = 이 판 다시 · q/Esc = 저장하고 종료. Ctrl+C 는 비상시에만 (진행 중 판 저장 안 됨).
- 결과: `eval/rollouts/<시각>_20k_t1_try3_filt/` — console.log, debug.log, dataset/, analysis.json, ep*_action_state.png, pose_check.txt
- 성공/실패 판정은 기록하지 않는다 (판정은 2번).
- T3 로 해 보려면 `TASK=t3`, tag 를 `try3_filt_t3` 처럼 바꾼다.

## 2. 평가 — eval_ui.py (판마다 시작 사진 + P/F 판정 → 결과표)

```bash
cd ~/so101_boxpick
python3 scripts/eval_ui.py --session main_k8/d2 --tag t1_eval_filt --episodes 8 \
  --inference.rtc.prefix_attention_schedule=EXP --inference.queue_threshold=30 --arm_filter=true
```

- eval_ui 기본 추론값(RTC · horizon 20 · steps 5)에 EXP · queue 30 · 필터만 덮어쓴다 → 1번과 같은 설정.
- `--arm_filter` 는 2026-10-26 eval_ui 에 추가 (세션 eval/rollout_logged.py 를 불러 씀). results.md 의 추론 줄에 `--arm_filter=true` 가 남는다.
- 흐름: 로딩 → ⏸ 큐브 놓고 →/Enter 로 시작 → ▶ 실행 (끝나면 →) → ↺ 처음 자세로 복귀 중 **P(성공)/F(실패)** 선택 → → 다음 판 · Esc 저장하고 끝 · ← 이 판 버리고 다시.
- 결과: `eval/rollouts/<시각>_32_20000_20k_t1_eval_filt/` (results.md · results.csv · start_images/ · dataset/ · 분석) + `eval/index.md`, `eval/results_all.csv` 에 누적.
- T3 평가: `--tag t3_eval_filt` 로 따로 실행 (방해물 놓고).
- 판 수·배치(K1–K8, 각도, Random)는 정해진 것이 없다. 예: K1→K8 순서로 1판씩 = 8판.
- 옵션만 확인 (팔·카메라 연결 안 함): 위 명령 끝에 `--check` → 2026-10-26 필터 켠 상태로 CHECK_OK 확인함 (arm_filter=True 표시).
