# 파지 자세(그리퍼 기울기)와 가시성 — d2 vs 레퍼런스 (2026-10-26)

CPU 분석과 설계만 했다. GPU 추론, 재학습, 로봇 작동, 레퍼런스 영상 내려받기는 하지 않았다. 기존 파일은 바꾸지 않았다.

새 파일 (이 폴더):
- `grasp_tilt.py` → `tilt_events.csv`, `tilt_summary.json`
- `visibility.py` → `visibility_frames.csv`
- `vis_analyze.py` → `vis_summary.json`

## 1. FK 와 좌표계 (근거)

- URDF: `~/Ros2/ros2_ws/src/twin_description/urdf/so101_new_calib.urdf`
  - 체인: base → shoulder_pan → shoulder_lift → elbow_flex → wrist_flex → wrist_roll → gripper_frame_joint (고정, 손가락 끝)
  - 회전축은 모두 각 프레임의 z.
- 관절각 → URDF 각 규약:
  - **A** = lerobot 도 그대로 (0 = 캘리브레이션 범위 중앙). 우리 twin 코드 `twin_backend/servo_map.py` 의 규약이다 (`theta = (ticks − mid)·2π/4095`).
  - **B** = A + (범위 중앙 − homing 자세) 관절별. 값은 `range_compare_20261021/calibration_compare.csv` 이고 두 팔이 다르다.
- 기울기 정의:
  - 접근축 = wrist_roll 회전축(손가락 쪽).
  - tilt = 접근축과 수직 아래 사이 각 (0° = 수직으로 내려 잡음).
  - pitch_r = 반지름 방향 성분 (+ = 손가락 끝이 로봇 바깥쪽).
  - lean_t = 접선 방향 성분.
- **wrist_roll 은 tilt 를 바꾸지 않는다:** 같은 자세에서 roll 만 −60…+60° 바꿨을 때 tilt 변화 0.0°.

**규약 검증** (파지 순간 손가락 끝 높이가 물체 높이로 일정해야 한다):

| | 판/이벤트 | 끝 높이 SD | 거리와의 상관 |
|---|---|---|---|
| 우리, A | 256 | 0.49 cm | −0.70 |
| 우리, **B** | 256 | **0.32 cm** | 0.21 |
| 레퍼런스, A | 770 | 1.07 cm | −0.63 |
| 레퍼런스, B | 770 | 1.01 cm | 0.56 |

→ 우리 팔은 B 가 더 맞는다. 레퍼런스는 어느 규약에서도 높이가 일정하지 않다. 스펀지 두께·눌림도 알 수 없어 레퍼런스 기울기의 절대값은 확정할 수 없다.

## 4. 기울기와 가시성 (질문 3–5, 우리 데이터 안)

- 방법: 판 사이 편상관. 같은 시점에서 tilt(B) 와 지표 각각에서 큐브 거리·방향의 선형 영향을 빼고 Spearman.
- 우리 판 사이 tilt SD 는 4–5° 다 (범위가 좁다).

| 지표 | 닫힘 2 s 전 ρ (p) | 1 s 전 | 0 s |
|---|---|---|---|
| front 빨강 보임 | +0.13 (.04) | +0.11 (.07) | +0.07 (.2) |
| front 로봇 가림 | −0.15 (.01) | −0.12 (.06) | −0.12 (.07) |
| front 큐브 밝기 비 | +0.36 (5e-9) | +0.07 (.2) | +0.08 (.2) |
| front 옆 탁자 밝기 비 | +0.30 (1e-6) | +0.06 (.3) | +0.22 (5e-4) |
| 상자 영역 밝기 비 | +0.11 (.09) | +0.13 (.04) | +0.09 (.2) |
| wrist 큐브 V | +0.31 (4e-7) | +0.20 (1e-3) | +0.07 (.2) |
| wrist 큐브 옆/먼 탁자 | −0.18 (4e-3) | +0.11 (.09) | +0.16 (.01) |
| wrist 손가락 가림 | +0.04 (.5) | −0.02 (.7) | +0.16 (.01) |
| wrist 선명도 | −0.12 (.06) | −0.26 (2e-5) | −0.09 (.1) |
| wrist 큐브 u | +0.51 (3e-18) | +0.26 (3e-5) | −0.31 (3e-7) |
| wrist 큐브 v | −0.22 (4e-4) | −0.12 (.06) | −0.12 (.06) |

- 우리 범위(B 기준 대략 0–10°) 안에서:
  - 더 기울수록 닫힘 2 s 전 front 의 큐브·옆 탁자가 덜 어둡다 (ρ 0.30–0.36).
  - 닫힘 순간의 front 가림과의 관계는 약하다 (\|ρ\| ≤ 0.15, p ≥ 0.06).
  - wrist 큐브 화면 위치는 기울기와 함께 바뀐다 (u: ρ −0.31…+0.51).
- 관측 자료의 상관이다. 기울기는 조작자가 고른 것이라 다른 요인(속도, 위치의 비선형 효과)과 섞일 수 있다.

## 5. 확인된 것 / 아닌 것

- **확인 (FK + URDF + 두 규약 범위):** 레퍼런스 파지는 우리보다 반지름 방향으로 더 기울어 있다. 크기는 규약에 따라 +7°…+40° 로 확정할 수 없다.
- **확인 (우리 영상):**
  - 닫힘 1 s 안 front 에서 큐브의 절반 이상이 안 보이고, 주원인은 로봇 몸체 가림이다.
  - 그림자는 큐브 −23%, 탁자 −14% 이고, 실내 조명은 변하지 않는다.
  - wrist 에서 손가락은 큐브를 가리지 않는다.
- **확인 안 됨:**
  - 레퍼런스의 front/wrist 가시성 (영상 없음)
  - 우리 범위 밖(20–45°) 기울기에서의 가림·그림자
  - 기울기 차이가 학습·정책 성능 차이의 원인이라는 것

## 6. Ablation 설계 (질문 8, 실행 안 함)

요인 3개를 따로 바꾼다:
- **자세:** 수직 (현재, B tilt ≤ 10°) vs 비스듬함 (반지름 바깥쪽 30–40°, 레퍼런스 B 수준)
- **조명:** 현재 vs 확산광 추가 (작업대 위 확산판 2개, 그림자 쪽)
- **카메라 입력 영역:** front 원본 vs front 작업영역 잘라 확대 (소프트웨어) — 그리고 필요하면 front 카메라 위치 변경 (하드웨어)

|---|---|---|---|---|
| S0 정적 | 사용자가 토크를 끈 팔을 손으로 정해진 파지 직전 자세(수직/비스듬, 높이 3단)에 두고, 큐브 6곳 × 조명 2 로 front·wrist 사진. 관절값은 읽기 전용으로 기록해 FK 로 기울기 확인 | 토크 끔, 사용자가 손으로 | 이 폴더 `visibility.py` 지표 (가림·그림자·조명·224 px), 라벨 품질 | 사진 72장 |

- 레퍼런스 가시성을 직접 재려면: 레퍼런스 영상 일부를 받아 같은 지표(파랑 스펀지 마스크)로 잰다. 판 8편이 든 파일만 받으면 수백 MB 수준이다 (승인 필요).
- **판정:**
  - S0 에서 비스듬한 자세의 front 가림이 수직보다 뚜렷이 작고(예: 닫힘 직전 보임 비율 +0.2 이상), wrist 그림자가 작으면 → S1 진행.

  - S2 에서 probe 오차가 요인에 따라 바뀌어야 S3 로 간다.
