대상: `main_k8/d2` (T1-K·T1-R·T3-K·T3-R 256편), 체크포인트 `train/32_20000/pi05_expert_bs32_20k/checkpoints/020000`.
읽기 전용 분석이다. 학습·평가·로봇 코드는 바꾸지 않았고 로봇과 카메라에는 연결하지 않았다. 오프라인 모델 추론은 GPU 에서 돌렸다 (d4 학습과 동시).

## 0. 좌표·부호

- C frame (cm): x = 로봇 → 상자 방향, y = 로봇 왼쪽. 로봇 base 는 (−31, 11) 로 추정했다 (pan 맞춤값, 실측 아님). FK 강체 맞춤으로 나온 값 (−31.6, 11.5) 과 일치한다.
- pan 기대값 = −bearing − 1.4°. **pan_res = pan − 기대값. + = 큐브보다 로봇 오른쪽 = front 영상 왼쪽.**
- 큐브 위치: 학습은 QA `qa/positions.csv` (첫 front 프레임 + H, ±0.3 cm). 평가는 같은 방법 (`grasp_table.front_cube`).
- 파지 순간: `check_dataset.first_grasp` 규칙 (팔로워 그리퍼). 평가는 재시도까지 모두 셌다 (`common.close_events`).

## 5. 확인하지 못한 것 · 한계

- 평가는 5판뿐이고 모두 T1 이다. T3 평가는 없다.
- 프로브는 첫 chunk 의 방향만 본다. 실물에서 벌어지는 닫힌 고리 (관측 → RTC 이어붙이기 → 다음 관측) 는 재현하지 않는다.
- 합성 grid 의 wrist 영상은 큐브 없는 중앙값이다. 학습 판 91/256 은 쉬는 자세에서도 wrist 에 빨강이 보인다.
- 실물 추론 영상은 MJPEG 원본이고, 학습·프로브 영상은 AV1(CRF 30) 디코드다.
- FK(`so101_new_calib.urdf`) 접선 오차는 큐브가 왼쪽/오른쪽이냐에 따라 사람 시연에서도 −2.3 / +2.4 cm 로 갈린다. 그래서 좌우 판단은 pan_res 를 기준으로 했다.
- 로봇 base 위치는 추정값이다. pan_res 의 절대값보다 사람 대비 차이(Δpan)가 더 직접적이다.

## 12. 2차 한계

- 영상 편집은 큐브 조각을 옮겨 붙인 것이다. 그림자·원근 변화, 손가락 앞에 겹치는 경우를 맞추지 않았다.
- wrist 축 보정은 사람 시연 마지막 1 s 집게 끝 이동(중앙값 접선 0.34 cm · 반지름 0.56 cm)이 작아서 잘 맞은 판이 45/128 이다. 128편 G 는 roll 관계식으로 만든 근사다.
- 실험 3 의 오프라인 재계획은 AV1 디코드 영상이고 RTC 안내를 넣지 않았다. 0–10 s 는 seed SD 가 11° 라 raw − 모델 차(−3.7°)를 가를 수 없다.
- pregrasp 정확도(실험 1)는 사람 궤적 state 를 넣은 결과다. 정책 자신의 닫힌 고리에서의 보정은 재현하지 않았다.
- 실험 2·4·exp2b 는 20k 만 했다.
