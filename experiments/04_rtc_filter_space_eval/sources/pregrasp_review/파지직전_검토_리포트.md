# 첫 파지 직전 검토 — 관절값 · front/손목 프레임 · 도달 위치 (학습 데이터 + 정책 평가)

작성 2026-10-20. 측정값만 담는다. 대상: 정책 평가 첫 파지 80판 (2026-10-19 A/B 40판 + 2026-10-20 공간 평가 40판), 학습 데이터(사람 텔레오퍼레이션) 첫 파지 380편 (redbox T1/T2/T3 × Known/Random).

## 1. 정의

- 파지 직전 = 첫 닫힘 순간: 그리퍼가 최대로 열렸다가 3° 넘게 닫히기 시작한 틱 (손가락이 큐브에 닿기 전).
- 관절값 (정책): 그 틱의 state(실제 위치) · sent(보낸 명령) · raw(정책 출력), 6개 서보 각각 → `pregrasp_review.csv`.
- 관절값 (학습): 그 프레임의 state(팔로워 실제 위치) · action(리더 팔 명령), 6개 서보 각각 → `pregrasp_review_train.csv`. 학습 데이터의 닫힘 순간은 train_roll_census 의 첫 파지 정의 (그리퍼가 큐브에 막힌 구간 직전 3° 닫힘 시작).
- 프레임: 같은 frame 번호의 front · 손목 영상 → 정책 `frames/<평가>_<판>_*.png`, 학습 `frames_train/<그룹>_ep<번호>_*.png` (front · wrist · sheet).
- 손목 정상 범위: 학습 데이터 사람 첫 파지 380편의 닫힘 순간 손목 화면 큐브 중심 5–95% — 가로 0.284–0.411, 세로 0.596–0.747 (화면 비율), 넓이 0.089–0.123. 분류는 ±0.02 여유를 둔다.
- 손목 카메라는 그리퍼에 고정되어 있다. 화면 위 = 그리퍼 앞쪽, 화면 아래 = 손가락 쪽, 가로 = 파지축 방향.
- 정렬 각도: 손목 화면에서 잰 파지축 대비 큐브 윗면 각도 (pregrasp_angles.csv).
- 계획 위치 = plan.csv 라벨. 2026-10-19 A/B 평가 1·4판은 실제로 K3·K4 에 놓였다 (영상 확인). 공간 평가 Z1–Z4 는 구역 안 자유 배치.
- 참고값 (분류에 쓰지 않음): 관절→위치 회귀로 추정한 도달 위치와 시작 큐브 위치의 거리. 학습 T1 첫 파지로 맞춤 (LOO 중앙 0.78 cm). 그리퍼가 탁자 높이에서 닫는다고 가정한다.

그림 표시 (`_sheet.png`): front — 노란 원 = 시작 큐브 위치 (학습: 잡은 큐브, 흰 원 = 다른 빨간 큐브), 자홍 X = 추정 도달 위치, 흰 + = K1–K4. 손목 — 노란 상자 = 큐브 **중심**이 들어와야 하는 정상 범위 (큐브 크기가 아님), 큐브 윤곽 초록 = 범위 안 / 빨강 = 범위 밖.
