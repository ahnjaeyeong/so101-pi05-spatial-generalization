# 큐브 각도 · 거리 · 손목 회전 분석 (2026-10-20)

데이터: 공간 평가 40판 (조건 B) + 2026-10-19 A/B 40판 = 80판. 세부 표: space_report.md (40판), space_report_pooled.md (80판).

## 측정
- 큐브 각도: 시작 front 화면 윤곽을 탁자 평면으로 펴서 잼. 로봇→큐브 방향 기준 0° = 면이 로봇 정면, 45° = 대각선.
  검증: 첫 파지 성공 45판에서 손목 회전(90° 주기)과 중앙 6.7° 차이, 76% 가 15° 안.
- 손목 회전 크기: 시작 → 첫 닫힘의 wrist_roll 변화.
- front 가림: 첫 닫힘 전 front 화면에서 큐브가 팔에 가려진 비율.

## 결과 (80판)
| 요인 | 구간 | 첫 파지 | 최종 |
|---|---|---|---|
| 손목 회전 | <30° | 21/32 (66%) | 29/32 (91%) |
| | 30–60° | 18/34 (53%) | 23/34 (68%) |
| | ≥60° | 6/14 (43%) | 7/14 (50%) |
| 거리 | <21 cm | 17/31 (55%) | 19/31 (61%) |
| | 21–24 cm | 7/15 (47%) | 11/15 (73%) |
| | ≥24 cm | 21/34 (62%) | 29/34 (85%) |
| 큐브 각도 | 0–15° | 12/24 (50%) | 15/24 (62%) |
| | 15–30° | 17/30 (57%) | 24/30 (80%) |
| | 30–45° | 16/26 (62%) | 20/26 (77%) |
- 최종 성공: 손목 <30° vs ≥60° p=0.005, 가까움 vs 멂 p=0.047. 첫 파지는 같은 방향이지만 p>0.1.
- 큐브 각도 자체는 성공과 일관된 관계 없음. 성공을 가르는 것은 큐브 각도가 아니라 정책이 손목을 얼마나 돌리는가.
- 손목 방향 쏠림: 80판 중 68판이 −방향으로 회전. 큐브가 +방향으로 돌아가 있으면 −(90−각도) 로 크게 돌림 → 45° 넘게 돈 판 36/80 (큐브 +방향 18/30, −방향 18/50).
  학습 텔레오퍼레이션(T1-K/T1-R)도 −방향 53/64, 49/64 — 사람 습관을 배움. 단 45° 넘게 돈 비율은 사람 21% vs 정책 45%.
- front 가림 가설은 지지 안 됨: 가림이 많은 판이 오히려 첫 파지 성공이 높음 (팔이 큐브 위에 제대로 온 결과로 보임).

## 해석·다음 단계
- 사용자 관찰("큐브 면이 비스듬하면 손목이 돌고, 손목이 돌면 공간 인식이 나빠짐")과 일치: 손목(카메라) 회전이 클수록 실패.
- 원인 후보: 학습 데이터의 한쪽 회전 습관 + 큰 회전 구간 데이터 부족. 대응 후보: (1) +방향 회전 시연 보강, (2) 큐브 각도를 고르게 한 데이터, (3) 추론 시 손목 회전을 90° 주기로 가까운 쪽으로 바꾸는 후처리(검증 필요).
- 가까운 거리(<21 cm)는 최종 성공이 낮음 — 쉬는 팔·손목 보드 근처.
