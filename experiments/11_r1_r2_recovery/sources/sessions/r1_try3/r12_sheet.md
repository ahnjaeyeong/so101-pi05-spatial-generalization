## 시나리오 설명

### R1-A — 접근 초반, Pan 이 큐브와 다른 방향을 향함 → 큐브 쪽으로 되돌려 접근 (1편)
- 시작 조건: 그리퍼 열림. 팔을 거의 접은 접근 초반 자세에서 Pan 을 주황 선 쪽 (큐브와 다른 방향) 으로 둠.
- 오차: Pan 을 큐브 방향보다 왼쪽/오른쪽 15·20·25–30° (후보, 대략)
- 목표 동작: 녹화 시작 → Pan 을 초록 선(큐브)으로 되돌리며 팔을 펴 접근 → 파지 → 상자 → 쉬는 자세.
- 손목 화면 큐브: 가장자리이거나 안 보여도 됨

### R1-B1 — 팔을 펴며 다가가는 도중 Pan 이 큐브에서 멀어지는 쪽으로 감 → 방향을 반대로 바꿔 복귀 (1편)
- 시작 조건: 그리퍼 열림. 준비 단계에서 팔을 일부 펴며 Pan 을 주황 쪽 (큐브에서 멀어지는 쪽) 으로 움직여 멈춤 (탁자 위 5 cm 이상).
- 오차: 접근 도중 Pan 이 큐브 방향에서 왼쪽/오른쪽으로 15·20° 벗어남 (후보, 대략)
- 목표 동작: 녹화 시작 → 바로 Pan 방향을 반대로 (초록 선 쪽) 바꿔 큐브로 접근 → 파지 → 상자 → 쉬는 자세. 멀어지는 쪽으로 더 가지 않는다.
- 손목 화면 큐브: 가장자리이거나 안 보여도 됨

### R1-B2 — 큐브 쪽으로 Pan 을 돌리며 오다 큐브 방향을 지나쳐 멈춘 상태 → 되돌아와 접근 (1편)
- 시작 조건: 그리퍼 열림. 준비 단계에서 반대쪽에서 큐브 쪽으로 Pan 을 돌리며 오다 초록 선을 지나 주황 쪽에서 멈춤 (팔 일부 폄).
- 오차: 큐브 방향을 왼쪽/오른쪽으로 15·20·25° 지나침 (반대쪽에서 와서 지나친 것, 후보, 대략)
- 목표 동작: 녹화 시작 → 왔던 방향과 반대로 Pan 을 되돌려 초록 선(큐브) → 접근 → 파지 → 상자 → 쉬는 자세.
- 손목 화면 큐브: 가장자리이거나 안 보여도 됨

### R1-B3 — 접근 도중 Pan 이 벗어나 손목 화면에서 큐브가 사라진 상태 (front 에는 보임) → 큐브를 다시 찾아 접근 (1편)
- 시작 조건: 그리퍼 열림. 팔을 일부 편 접근 자세에서 Pan 을 주황 쪽으로 벗어나 손목 화면에 큐브가 없게 둠. front 에는 큐브가 보여야 함.
- 오차: 손목 화면에 큐브가 안 보일 만큼 (보통 20–25°) 벗어남 (후보, 대략)
- 목표 동작: 녹화 시작 → 큐브 쪽으로 Pan 을 되돌려 손목 화면에 큐브를 다시 찾고 → 접근 → 파지 → 상자 → 쉬는 자세.
- 손목 화면 큐브: 가장자리이거나 안 보여도 됨
