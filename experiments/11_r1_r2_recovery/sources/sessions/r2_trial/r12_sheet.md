## 시나리오 설명

### R2-AHEAD — 큐브가 손가락 끝보다 앞에 있음 (1편)
- 시작 자세: 그리퍼 열림, 좌우 중심은 맞음, 파지 높이. 큐브가 아직 손가락 사이에 들어오지 않음.
- 시연: 큐브가 손가락 사이에 다 들어올 때까지 전진한 뒤 닫기 → 들어 올리기 → 상자 → 쉬는 자세.
- 손목 화면 큐브: 보여야 함

### R2-LEFT — 큐브 중심보다 왼쪽으로 어긋남 (1편)
- 시작 자세: 그리퍼 열림, 파지 높이·깊이 근처. 손가락 사이 중심이 큐브보다 왼쪽.
- 시연: 옆으로 고쳐 중심을 맞춘 뒤 닫기 → 상자 → 쉬는 자세.
- 손목 화면 큐브: 보여야 함

### R2-HIGH — 가운데지만 접근 깊이(높이) 부족 (1편)
- 시작 자세: 그리퍼 열림, 큐브 바로 위 가운데. 손가락이 아직 큐브 옆면까지 내려오지 않음.
- 시연: 손가락이 큐브 옆면을 감쌀 때까지 내려간 뒤 닫기 → 상자 → 쉬는 자세.
- 손목 화면 큐브: 보여야 함
