## 시나리오 설명

### R2-P-AHEAD — 큐브가 손가락 끝보다 앞에 있음 (아직 손가락 사이 밖) (2편)
- 시작 조건: 그리퍼 열림, 파지 높이 근처에서 팔 정지. 큐브가 손가락 끝보다 앞 (손목 화면 주황 영역). 큐브에 닿지 않음.
- 오차: 손가락 끝과 큐브 앞면 사이 1.5–3 cm (손목 화면 큐브가 위쪽·작게)
- 목표 동작: 녹화 시작 → 그리퍼를 연 채 유지 → 부족한 접근 깊이 · 높이 · 정렬을 고침 (어느 관절로 고칠지는 시연자가 화면을 보고 정함) → 큐브가 손가락 사이에 오면 d2 방식으로 한 번 닫기 → 들어 올리기 → 상자 → 쉬는 자세.
- 손목 화면 큐브: 보여야 함

### R2-P-DEPTH — 큐브가 손가락 사이에 일부만 들어옴 (손가락 끝에 걸침) (2편)
- 시작 조건: 그리퍼 열림, 파지 높이 근처에서 팔 정지. 큐브가 손가락 끝 사이에 일부만 들어옴 (손목 화면 주황 영역). 큐브를 밀지 않음.
- 오차: 0.5–1.5 cm 덜 들어감 (손목 화면 큐브가 닫기 영역 바로 위)
- 목표 동작: 녹화 시작 → 그리퍼를 연 채 유지 → 조금 더 진입 · 정렬 (고칠 관절은 시연자가 정함) → 큐브가 손가락 사이에 오면 한 번 닫기 → 들어 올리기 → 상자 → 쉬는 자세.
- 손목 화면 큐브: 보여야 함
