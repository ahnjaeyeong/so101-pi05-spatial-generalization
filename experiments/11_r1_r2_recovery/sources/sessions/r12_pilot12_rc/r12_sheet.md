## 시나리오 설명

### RC-F1 — 그리퍼가 비스듬히 큐브 앞쪽에서 내려와 모서리에 닿기 직전 (4편)
- 시작 조건: 그리퍼 열림. 그리퍼를 비스듬히 기울여 큐브 앞쪽 · 큐브 높이에서, 손가락 끝이 큐브 앞 위 모서리 바로 앞 (닿지 않게) 에서 정지.
- 오차: 손가락 끝과 큐브 앞면 사이 1.5–3 cm (손목 화면 큐브가 위쪽·작게)
- 목표 동작: 녹화 시작 → 살짝 들어 올려 모서리에서 떨어짐 → 큐브 바로 위로 옮기며 그리퍼를 수직으로 → 곧게 내려가 큐브가 손가락 사이에 오면 한 번 닫기 → 상자 → 쉬는 자세.
- 손목 화면 큐브: 보여야 함

### RC-F2 — 그리퍼가 큐브 바로 위에서 일찍 닫힌 채 멈춤 (4편)
- 시작 조건: 그리퍼 닫힘 (쉬는 자세 그대로). 큐브 바로 위, 손가락 끝이 큐브 윗면보다 1.5–2.5 cm 위에서 정지. 큐브에 닿지 않음. 큐브 앞에서 닫는 동작 (빈 파지) 은 하지 않음.
- 오차: 0.5 cm 이내 (손목 화면 큐브가 이미 초록 닫기 영역 안)
- 목표 동작: 녹화 시작 → 먼저 그리퍼를 충분히 연다 (약 30) → 열린 채 내려가 큐브가 손가락 사이에 오면 한 번 닫기 → 상자 → 쉬는 자세.
- 손목 화면 큐브: 보여야 함

### RC-F3-L — 그리퍼가 닫힌 채 큐브 왼쪽으로 빗겨 멈춤 (2편)
- 시작 조건: 그리퍼 닫힘. 파지 높이에서 손가락 사이 중심이 큐브보다 로봇 왼쪽으로 2–3 cm (손목 화면에서 큐브가 오른쪽). 큐브에 닿지 않음.
- 오차: 손가락 사이 중심이 큐브 왼쪽 1.5·2.5·3.5 cm (판마다, 손목 화면 큐브가 오른쪽)
- 목표 동작: 녹화 시작 → 그리퍼를 연다 → 좌우를 맞춰 큐브가 손가락 사이 가운데에 오게 → 한 번 닫기 → 상자 → 쉬는 자세.
- 손목 화면 큐브: 보여야 함
