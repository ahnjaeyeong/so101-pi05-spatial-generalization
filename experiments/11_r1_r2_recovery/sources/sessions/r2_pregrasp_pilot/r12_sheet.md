## 시나리오 설명

### R2-DEPTH — 큐브가 손가락 사이에 일부만 들어옴 (손가락 끝에 걸침) (8편)
- 시작 조건: 그리퍼 열림, 좌우 중심 맞음, 파지 높이. 큐브가 손가락 끝 사이에 걸칠 만큼만 들어온 자세 (손목 화면 주황 영역).
- 오차: 0.5–1.5 cm 덜 들어감 (손목 화면 큐브가 닫기 영역 바로 위)
- 목표 동작: 조금 더 밀어 넣어 큐브가 초록 닫기 영역에 들어오면 한 번 닫기 → 들어 올리기 → 상자 → 쉬는 자세.
- 손목 화면 큐브: 보여야 함

### R2-AHEAD — 큐브가 손가락 끝보다 앞에 있음 (아직 손가락 사이 밖) (8편)
- 시작 조건: 그리퍼 열림, 좌우 중심 맞음, 파지 높이. 큐브가 손가락 끝보다 1.5–3 cm 앞 (손목 화면 주황 영역).
- 오차: 손가락 끝과 큐브 앞면 사이 1.5–3 cm (손목 화면 큐브가 위쪽·작게)
- 목표 동작: 큐브가 손가락 사이 가운데(초록 닫기 영역)에 올 때까지 전진한 뒤 한 번 닫기 → 들어 올리기 → 상자 → 쉬는 자세.
- 손목 화면 큐브: 보여야 함

### R2-LEFT — 손가락 사이 중심이 큐브보다 로봇 왼쪽 (4편)
- 시작 조건: 그리퍼 열림, 파지 높이·깊이 근처. 손가락 사이 중심이 큐브보다 왼쪽 (손목 화면 주황 영역 = 큐브가 오른쪽에 보임).
- 오차: 손가락 사이 중심이 큐브 왼쪽 1.5·2.5·3.5 cm (판마다, 손목 화면 큐브가 오른쪽)
- 목표 동작: 손목·팔로 옆으로 고쳐 큐브가 초록 닫기 영역에 오면 한 번 닫기 → 상자 → 쉬는 자세 (작은 Pan 수정 허용).
- 손목 화면 큐브: 보여야 함

### R2-RIGHT — 손가락 사이 중심이 큐브보다 로봇 오른쪽 (4편)
- 시작 조건: 그리퍼 열림, 파지 높이·깊이 근처. 손가락 사이 중심이 큐브보다 오른쪽 (손목 화면 주황 영역 = 큐브가 왼쪽에 보임).
- 오차: 손가락 사이 중심이 큐브 오른쪽 1.5·2.5·3.5 cm (판마다, 손목 화면 큐브가 왼쪽)
- 목표 동작: 손목·팔로 옆으로 고쳐 큐브가 초록 닫기 영역에 오면 한 번 닫기 → 상자 → 쉬는 자세 (작은 Pan 수정 허용).
- 손목 화면 큐브: 보여야 함

### R2-READY — 파지 가능한 위치에 거의 도달 (정상 파지 준비) (8편)
- 시작 조건: 그리퍼 열림, 큐브가 손가락 사이 거의 가운데 (손목 화면 큐브가 초록 닫기 영역 안).
- 오차: 0.5 cm 이내 (손목 화면 큐브가 이미 초록 닫기 영역 안)
- 목표 동작: 필요하면 아주 작게 고친 뒤 한 번 닫기 → 상자 → 쉬는 자세. 일부러 기다리지 않는다.
- 손목 화면 큐브: 보여야 함
