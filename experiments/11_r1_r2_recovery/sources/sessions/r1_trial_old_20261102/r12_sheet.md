## 시나리오 설명

### R1-L — 접근 방향이 큐브 왼쪽으로 빗나감 (1편)
- 시작 자세: 그리퍼 열림. 큐브 높이보다 3–5 cm 위에서 Pan 을 큐브보다 왼쪽으로 돌려 둔 자세 (큐브는 손목 화면 한쪽에 치우쳐 보임).
- 시연: Pan 을 큐브 쪽으로 되돌려 중심을 맞춘 뒤 내려가 정상 파지 → 상자 투입 → 처음 자세(쉬는 자세).
- 손목 화면 큐브: 보여야 함

### R1-R — 접근 방향이 큐브 오른쪽으로 빗나감 (1편)
- 시작 자세: 그리퍼 열림. 큐브 높이보다 3–5 cm 위에서 Pan 을 큐브보다 오른쪽으로 돌려 둔 자세.
- 시연: Pan 을 큐브 쪽으로 되돌려 중심을 맞춘 뒤 내려가 정상 파지 → 상자 투입 → 쉬는 자세.
- 손목 화면 큐브: 보여야 함

### R1-OL — Pan 이 큐브를 지나 왼쪽까지 감 (지나침) (1편)
- 시작 자세: 그리퍼 열림. 오른쪽에서 왼쪽으로 오다 큐브를 지나친 자세 — 큐브가 손목 화면 가장자리이거나 안 보임.
- 시연: 왔던 방향과 반대로 Pan 을 되돌려 큐브를 다시 화면 가운데에 두고, 중심 접근 후 파지 → 상자 → 쉬는 자세.
- 손목 화면 큐브: 가장자리이거나 안 보여도 됨
