## 3. d2 참고 시연 (`tools/r12_guide.py`)

색인 (한 번 만듦, d2 읽기만, 65–78 s):
- 명령: `tools/r12_guide.py build`
- 출력: `reference/` (git 제외, 24 MB) — 256 편 키프레임 front · wrist 320×240 jpg, 관절 · 그리퍼 기록값, 손목 큐브 검출, 닫기 전후 궤적.

키프레임 (판마다, d2 기록에서 계산):

| 키 | 정의 | 256 편 중앙 (닫기 시작 기준) |
|---|---|---|
| k_open | 리더 그리퍼 명령이 15 를 넘은 마지막 순간 (열기 시작) | −2.03 s, 팔로워 5.6 |
| k_opened | 팔로워 그리퍼가 그 구간 최대의 90 % 에 처음 닿음 (다 열림) | −1.67 s, 팔로워 29.9 |
| k_reach | 팔 관절 속도가 마지막으로 15 °/s 를 넘은 다음 (접근 멈춤) | −0.43 s, 손목 v 0.69 |
| k_close | 리더 첫 닫힘 시작 (r2_common.close_onsets, below_review 와 같은 규칙) | 0, 손목 v 0.71 |
| k_grasp | 닫기 뒤 1.5 s 안 팔로워 그리퍼 바닥 | +0.45 s, 바닥 12.6 (256 편 모두 ≥ 8 = 쥠) |
| k_done | 마지막 프레임 | +6.55 s |

R2-P 단계 ↔ 키: ① k_opened · ② k_reach · ③ k_close · ④ k_grasp · ⑤ k_done (`config/r12_pilot12.yaml` guide_stages).

고르기:
- 계획 큐브 자리 (front 검출이 계획에서 2 cm 넘게 떨어지면 검출 자리) 와 각도 코드로 점수를 낸다. 점수 = 거리 + 각도 다르면 3 cm. 첫 닫힘에 쥔 판만 후보다.
- 일치 정도:
  - 높음: 2 cm 안 · 같은 각도
  - 보통: 4 cm 안
  - 낮음: 그 밖 — 거리를 표시하고 '참고만' 이라고 적는다
- 접근 자세 · roll 은 비교하지 않는다. 화면에도 '자세는 판마다 다름' 이라고 적었다.
- 참고 시연은 준비 단계에서만 고르고, 녹화 · 결과 단계에서는 고정한다 (큐브를 옮기면 검출 자리가 바뀌므로).

## 4. 자동 단계 추정 · 녹화 뒤 검토 (보조)

자동 단계 (R2-P):

| 상황 | 단계 |
|---|---|
| 준비 단계 | ① |
| 녹화 중 팔이 움직임 | ② |
| 손목 큐브가 닫기 영역 안 (2D) | ③ |
| 닫힘 뒤 팔로워 그리퍼 ≥ 8 | ④ |
| 파지 뒤 팔이 15° 넘게 이동 | ⑤ |
| 빈 파지 (팔로워 ≤ 5) 뒤 다시 엶 | ② + '빈 파지 의심' |

- 표시는 '자동 추정 (보조)' 이고, 사용자가 고른 단계가 우선한다.

녹화 뒤 검토:
- 녹화 프로세스가 틱마다 팔로워 그리퍼 값을 남긴다 (`last_episode.json` grip_state — 녹화 dataset 과 별개, 기록 값 · 형식 변화 없음).
- 첫 닫힘 뒤 1.5 s 안 팔로워 바닥이 ≤ 5 면 '빈 파지 의심', 5–8 이면 '확인 필요' 다 (r2_common 규칙).
- 파지 전에 실패한 닫힘 횟수를 센다.
- 첫 닫힘 때 축소 손목 영상에서 큐브가 경계에 닿았는지 (잘림) 본다.
- 결과 단계 화면 · 터미널 · `r12_attempts.jsonl` (review_flags) · `r12_pilot_episodes.csv` (review_flags 열) 에 남는다.
- 판정이 아니라 영상 확인을 돕는 표시다.

QA:
- Q5 를 '파지 전 닫힘' 기준으로 고쳤다. 전에는 상자에 놓고 다시 닫는 것도 세어 정상 판도 check 였다.
- 첫 닫힘 때 잘림을 추가했다.
- 큐브가 잘렸을 때 닫기 영역 문구를 '위치 판정 불확실' 로 바꿨다 (전에는 '더 진입' 으로 틀리게 나옴).

## 6. R1 · R2-O 로 넓히기 (설계, 아직 안 함)

같은 구조:
- 설정 `guide_stages` 만 넣으면 단계 띠 · 참고 칸 · 오버레이가 켜진다.
- 단계마다 `ref` 를 키 이름 또는 `none` 으로 둔다.
- `none` 단계는 썸네일 자리에 'd2 참고 없음' 이 나오고, 참고 칸 · 오버레이에도 참고 큐브를 그리지 않는다. d2 에 없는 복구를 정답처럼 보여 주지 않기 위해서다.

| 시나리오 | 단계 (ref) |
|---|---|
| R2-O | ① 닫힌 채 정지 (none) → ② 충분히 열기 (none — 그리퍼 값만 d2 '다 열림' 기록 범위를 글로 표시 검토) → ③ 접근·정렬 (k_reach) → ④ 닫힘 직전 (k_close) → ⑤ 다시 닫기 (k_grasp) → ⑥ 완료 (k_done) |
| R1 | ① 지나친 시작 (none) → ② Pan 복구 (none) → ③ 접근 (k_opened) → ④ 닫힘 직전 (k_close) → ⑤ 파지 (k_grasp) → ⑥ 완료 (k_done) |

필요한 추가:
- `auto_stage` 에 R2-O 재개방 규칙 (명령 < 15 → ①, 오르는 중 → ②) 과 R1 Pan 복구 규칙 (복구 방향 이동 → ②).
- R1 은 front 지도에 이미 지나침 선이 있어 단계 띠와 함께 쓴다.
