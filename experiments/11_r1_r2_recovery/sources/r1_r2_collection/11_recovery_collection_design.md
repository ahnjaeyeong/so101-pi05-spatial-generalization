## 0. 바뀐 원칙 (사용자 결정, 11-04)

1. **회복 장면만 녹화한다.** 실패를 만드는 동작은 준비 단계에서 하고 녹화하지 않는다. 녹화는 회복 → 파지 → 상자 → 쉬는 자세.
2. **시작 위치를 정확히 정한다.** 시작 자세는 실물 추론에서 실제로 일어난 실패 장면을 기준으로 한다. 그 장면의 관절값 · 큐브 자리 · 큐브 각도 · 그리퍼 상태 · 손목/front 화면을 사용한다. 개념도와 대략적인 영역은 쓰지 않는다.
3. **수집자가 실패를 알고 찍는다.** 실패 종류마다 이름 · 대표 영상 · 시작 장면이 있다. 준비 단계 화면에서 실제 실패 장면과 지금 화면을 나란히 비교한다.

이전 R2-P (AHEAD/DEPTH) 는 대략적인 시작 영역 기준이었다. 실물 실패 영상에서 사용자가 본 실패 유형과 맞지 않아 이 설계로 바꾼다 (R2-P ep2–5 데이터는 그대로 보존).

## 3. 시나리오 (회복 녹화)

| 시나리오 | 준비 (녹화 안 함) | 녹화 = 회복 | 하지 말 것 |
|---|---|---|---|
| RC-F1 사선 하강 | 템플릿 큐브 자리 · 각도에 큐브. 팔을 템플릿 관절값으로 (그리퍼 상태도 템플릿대로), 손목 화면이 템플릿 장면과 같아지면 멈춤. 큐브에 닿지 않음 | 살짝 들어 올림 → 큐브 바로 위로 다시 맞춤 (그리퍼 충분히 열기) → 수직으로 내려감 → 한 번 닫기 → 상자 → 쉬는 자세 | 사선으로 더 밀고 들어가기 · 모서리를 누른 채 닫기 |
| RC-F2 이른 닫힘 | 같은 방식 (F2-a: 그리퍼 열림, 큐브가 손목 화면 아래쪽) | 닫지 않고 → 큐브가 손가락 사이에 오도록 위치를 고침 → 한 번 닫기 → 상자 → 쉬는 자세 | 그 자리에서 바로 닫기 |
| RC-F3 정렬 오차 | 같은 방식 (F3-a: 그리퍼 닫힘, 큐브가 왼쪽 손가락 바깥) | 그리퍼 열기 → 좌우 정렬 → 한 번 닫기 → 상자 → 쉬는 자세 | 어긋난 채 닫기 |

- 큐브에 손가락이 닿거나 큐브가 움직인 상태로 시작하지 않는다. 움직였으면 다시 놓는다.
- 템플릿 그리퍼가 '닫힘' 인 경우 (F1-a · F1-b · F3-a): 정책이 실제로 닫힌 채 다가간 상태다. 준비에서 닫힌 채 그 자세로 간다. 이때 빈 파지 동작 (큐브 앞에서 닫기) 은 하지 않는다. 쉬는 자세의 닫힌 그리퍼 그대로 간다.
- 정답 동작의 관절 경로는 정하지 않는다 (어느 관절로 고칠지는 시연자가 정함).

수량 (파일럿 안): 템플릿마다 2 판 = 12 판 (F1 6 · F2 2 · F3 4). 실패 판이 더 판정되면 템플릿을 늘린다.

## 4. 수집 화면 (구현할 것)

수집자 모드 3 칸을 그대로 쓰되 내용을 바꾼다.

| 칸 | 준비 단계 | 녹화 중 |
|---|---|---|
| ① | 실패 이름 · 사용자 설명 · 대표 영상 다시 보기 키 · 배치 순서 · **관절 목표 표** (지금 − 목표, 관절마다 ✓ ±5° / roll ±10° / 그리퍼 열림·닫힘) | 회복 단계 할 일 |
| ② | 손목 실시간 | 손목 실시간 |
| ③ | **실제 실패 장면 손목 프레임** (템플릿 시작 순간) + 작게 front 프레임 | 닫기 직전 목표 (d2 사람 성공 프레임 또는 개념도) |

- front 영상: 템플릿 큐브 자리 · 각도 윤곽 (흰 점선, 자유 좌표 지원 필요 — 지금은 K/F 자리만).
- 관절 목표가 맞지 않아도 녹화를 막지 않는다 (11-02 사용자 결정: 안전 BLOCK 만 막음). 시작 상태와 템플릿의 차이를 기록한다 (`start_vs_template`: 관절 차 · 손목 큐브 uv 차).
- 대표 영상: 창 키 (예: F11) 로 ③ 칸에서 템플릿 판 클립 재생.

## 6. 확인 안 된 것

- 이 회복 데이터로 학습했을 때 실패가 줄어드는지 (학습 · 평가 필요).
- 사람이 리더 팔로 템플릿 관절값을 ±5° 안으로 맞출 수 있는지 (실물 연습 필요).
- 사선 하강 (F1) 의 '사선' 을 관절값으로 어떻게 정의하는지 — 지금은 사용자 영상 판정뿐.
- 시작 후보 시각 (§2) 이 회복 시작으로 맞는지 — 사용자 확인 필요.
- HIL (정책 실행 중 넘겨받기, EXP-12 PLANNED) 은 이 설계에 포함하지 않는다.
