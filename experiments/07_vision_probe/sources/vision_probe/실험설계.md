## A. CPU 검사 결과 (측정값)

### A1. d2 의 Vision·VLM 가중치는 pi05_base 와 같다
`safe_open` 으로 텐서를 하나씩 비교했다 (d2 키 앞의 `model.` 를 떼고 매칭; vision·Gemma 는 7개 중 1개꼴로 표본).

| 묶음 | 비교한 텐서 | bit 단위 같음 | 최대 차 |
|---|---|---|---|
| vision_tower (SigLIP) | 63 | 63 | 0 |
| multi_modal_projector | 2 | 2 | 0 |
| Gemma 2B (language_model) | 23 | 23 | 0 |
| action expert (gemma_expert) | 201 | 1 | 0.02 |
| action in/out proj · time MLP | 9 | 1 | 0.019 |

→ probe 할 vision/VLM 특징은 **pi05_base 의 특징과 같다** (`train_expert_only` 로 고정됨, pi05_base snapshot 22c30e5).

특징 모양 (체크포인트 메타):
- SigLIP: 27층, 폭 1152, 224×224 입력 → 16×16 = 256 토큰. 640×480 은 224×168 로 줄어 위아래가 패딩되므로, 실제 영상은 16×12 패치이고 패치 1개 ≈ 원본 40 px.
- projector: 1152 → 2048.
- Gemma: 18층, 폭 2048, KV head 1개 × 256 (k_proj/v_proj 2048→256).
- action expert: 18층, 폭 1024. 층마다 prefix 의 K/V 를 읽는다.

### A2. wrist 영상 라벨 (`labels.py`, 256편 12,290 프레임 표본)
- **카메라는 고정 집게에 붙어 있다.**
  - 오른쪽(고정) 손가락 끝의 위치는 열림과 관계없이 중앙값 (368, 304) px 다. 구간별 SD 23–50 px 는 오검출 때문이다.
  - 왼쪽(움직이는) 손가락 끝은 열림에 따라 u 중앙값이 0 → 283 px 로 움직인다.
- 두 손가락 끝 검출률: 닫힘 직전 0.34 s 안 98%, 1–2 s 전 84%, 2–3 s 전 63%. 실패 원인은 테두리에 닿거나, 상자·어두운 큐브를 손가락으로 오인한 경우다 (`label_examples.jpg`).
- **큐브 검출률:** 닫힘 3 s 안 100%, 테두리 안 닿음 95–100%.
- 그래서 라벨은 손가락 검출에 의존하지 않게 정했다 (`splits.py`):
  - 기준점 u\*(d), v\*(d) = 사람 시연 파지 1 s 안 큐브 중심을 a + b/√넓이 로 맞춘 것 (거리에 따른 시차 반영).
  - 이 맞춤의 잔차 SD 는 u 0.43 cm, v 0.29 cm 다 (= 사람 정렬 변동 + 라벨 잡음 → **라벨 바닥**).
  - rel_u_cm, rel_v_cm = (큐브 중심 − 기준점) / (√넓이/2.5) ← 영상 좌표계 (roll 보정 전)
  - tan_cm, rad_cm = roll 로 회전 (θ = 0.91·roll − 5.5°, exp2b 사람 시연 맞춤), 부호 = 큐브 − 집게 ← 탁자 좌표계 (roll 보정 후)
- probe 사용 프레임: 큐브 있음 · 테두리 안 닿음 · 넓이 ≥ 3,000 px · 닫힘 3 s 안 → **7,810 프레임 / 256편**.

| 닫힘까지 | 프레임 | rel_u SD | rel_v SD | tan SD | rad SD | \|tan\| 90% |
|---|---|---|---|---|---|---|
| 0–1 s | 2,721 | 0.43 | 0.29 | 0.31 | 0.41 | 0.51 cm |
| 1–2 s | 2,774 | 0.65 | 0.52 | 0.52 | 0.69 | 1.18 cm |
| 2–3 s | 2,816 | 0.87 | 0.50 | 0.64 | 0.94 | 1.46 cm |

- probe 프레임의 roll SD 는 26.6° 다. tan 과의 상관: rel_u 0.31, rel_v −0.80.

### A3. 라벨 타당성 (사람 행동으로 검증)
'지금 라벨'이 '그 뒤 파지까지의 실제 좌우 이동'(파지 pan − 지금 pan, cm 환산, + = 로봇 왼쪽)을 설명하는 정도:

| 닫힘까지 | n | corr(tan_cm) | R² tan (roll 보정 후) | R² (rel_u, rel_v) 선형 (보정 전, 고정 사상) | 앞으로 좌우 이동 SD |
|---|---|---|---|---|---|
| 0.5–1 s | 1,215 | +0.36 | 0.13 | 0.10 | 0.26 cm |
| 1–2 s | 2,529 | +0.57 | 0.32 | 0.26 | 0.42 cm |
| 2–3 s | 2,560 | +0.72 | 0.51 | 0.16 | 0.53 cm |

→ roll 보정 라벨이 사람의 다음 좌우 교정과 더 잘 맞는다 (2–3 s: R² 0.51 vs 0.16).

### A4. 학습/평가 분리 (`splits.py` → `folds.json`)
- 판 단위로 나눈다. 같은 판의 프레임은 한쪽에만 들어간다 (모든 fold 에서 겹침 0 확인).
- 위치 hold-out:
  - Known: K 를 좌표로 지정 (2 cm 안 127/128편; K5 15편, 나머지 16편). K 쌍 (K1,K6) (K2,K7) (K3,K4) (K5,K8) 을 fold 0–3 의 test 로 둔다.
  - Random: 큐브 위치 k-means 5군집 → fold f 의 test 는 군집 f.
- 위치 완충: test 큐브 위치 3 cm 안에 큐브가 있던 판은 train 에서 뺀다.

| fold | test 판 | train 판 | 완충으로 뺀 판 | test 프레임 | train 프레임 |
|---|---|---|---|---|---|
| 0 | 58 | 175 | 23 | 1,784 | 5,319 |
| 1 | 51 | 165 | 40 | 1,520 | 5,058 |
| 2 | 49 | 182 | 25 | 1,496 | 5,564 |
| 3 | 69 | 135 | 52 | 2,122 | 4,106 |
| 4 | 28 | 194 | 34 | 857 | 5,928 |

- 외부 test: d2 실물 평가 롤아웃 5판 (정책이 만든 상태 + 새 위치). 같은 라벨 규칙을 적용한다 (아직 라벨 안 뽑음).

## B. 설계

### 1. 상대 좌표 추출 (질문 1)
- **큐브 중심:** 빨강 마스크 덩어리 중심 (검출 100%, 닫힘 3 s 안).
- **집게 중심:** 손가락 끝 직접 검출은 63–98% 로 불안정하다. 그래서 '카메라가 고정 집게에 붙어 영상 속 집게 기준점이 고정'이라는 사실(A2)을 쓴다. 사람 파지 기준점 u\*(d), v\*(d) 를 대신 쓰고, 손가락 끝 검출은 교차 검사용으로만 둔다 (두 끝 모두 잡힌 프레임에서 두 정의의 차이를 보고).
- **cm 환산:** 큐브 겉보기 크기 √넓이/2.5 px/cm (exp2b 의 사람 시연 보정 A ≈ 66–79 px/cm 와 같은 크기, 중앙값 73.7).

### 2. Vision Encoder linear probe (질문 2)
- **특징:** SigLIP 마지막 층 출력 (projector 전), wrist 영상 256 토큰 × 1152.
  - 비교용으로 SigLIP 중간 층 {9, 18} 와 projector 출력(2048)도 본다.
  - front 영상 토큰도 같은 방식으로 뽑아 'front 만으로' 상대 위치를 예측하는 대조군을 둔다.
- **probe 3종** (모두 선형 또는 거의 선형, 용량을 작게):
  - P1 (엄격 선형): 토큰마다 고정 무작위 사영 1152→64 (같은 사영을 모든 fold 에) → 256×64 = 16,384 차원 펼침 → ridge. λ 는 train 안에서 판 단위 내부 CV.
  - P2 (위치 보존 주의 probe): 점수 sᵢ = wᵀhᵢ, softmax 가중 pᵢ; 예측 = Σ pᵢ (gᵢ + B hᵢ). gᵢ = 패치 격자 좌표 (고정), B 는 2×d 선형. 파라미터 수 3d (CPU Adam).
  - P3 (대조 · 평균 풀링): mean-pool → ridge. 위치 정보가 사라지는 풀링이라 '공간 토큰이 필요한가'를 보는 대조군.
- **기준선:** wrist RGB 32×24 다운샘플 ridge (원시 픽셀), 빨강 마스크 64×48 ridge (이상적 분할의 선형 상한), state 6관절만 ridge, train 라벨을 판 단위로 섞은 shuffle (우연 수준).
- **타깃:** (rel_u_cm, rel_v_cm), (tan_cm, rad_cm), 큐브 크기(거리).

### 3. VLM 출력 probe (질문 3)
- **추출:** prefix 전체 (front + wrist + 문장·state 토큰) 를 한 번 forward 한다. 우리 `probe_core.Engine._prefix` 와 같은 경로에서 `output_hidden_states` 를 받는다.
- **저장:**
  - 층 {0, 3, 7, 11, 14, 17} 의 wrist 토큰 위치 **K·V (각 256)** — action expert 가 실제로 읽는 값이다.
  - 같은 층의 hidden(2048) 은 고정 무작위 사영 256 으로 저장한다.
  - state 토큰 위치 hidden 도 같은 사영으로 저장한다.
- **같은 probe:** P1–P3 를 층마다 적용한다.
- **추가 타깃:** 탁자 좌표계 (tan, rad). 영상만으로는 roll 을 알 수 없지만, prefix 안에서 wrist 토큰이 state 토큰(roll)을 볼 수 있으므로 (prefix 는 양방향 attention) VLM 층에서는 이 합성이 가능할 수 있다.
- **저장량 추정:** 프레임당 SigLIP 0.59 MB + KV 1.57 MB + 사영 hidden 0.39 MB ≈ 2.6 MB → 약 1.07만 프레임 ≈ 28 GB (디스크 여유 507 GB).
  - 1.07만 = 학습 7,810 + 편집 반사실 세트 약 1,900 + 평가 롤아웃 약 1,000.

### 4. Roll 보정 전후 비교 (질문 4)
같은 특징에 대해 4가지를 나란히 보고한다:
- (a) 영상 좌표 타깃 (rel_u, rel_v)
- (b) 탁자 타깃 (tan, rad) 을 특징만으로
- (c) (a) 의 예측을 roll 로 해석적으로 회전한 (tan, rad)
- (d) 특징 + [sin θ, cos θ] 와 그 곱을 넣은 선형 (roll 을 명시적으로 줌)

판단:
- (a) 좋음 & (b) 나쁨 & (c)≈(d) 좋음 → '표현은 정확, roll 과의 합성이 필요'.
- VLM 층에서 (b) 가 (a) 수준이면 → 고정 VLM 이 이미 roll 합성을 한다.
- 함께 볼 것: roll 구간별 (|roll| < 15°, 15–35°, > 35°) 오차.

### 5. 일반화 평가 (질문 5)
- **주 지표:** A4 의 5-fold (판 분리 + 위치 hold-out + 3 cm 완충) 에서 test fold 만으로 계산한다. 정규화·사영·λ 선택도 train fold 안에서만 한다.
- **보조:**
  - 평가 롤아웃 5판 (분포 밖 상태)
  - 편집 반사실 세트: exp2 와 같은 wrist 큐브 ±1 cm 이동, pre 단계 128편. 이 편집 프레임은 train 에 넣지 않는다.
- **표시:** MAE (cm), 축별 R², 닫힘까지 시간 구간별 (0–1, 1–2, 2–3 s), Known vs Random test, 판 단위 bootstrap 95% CI.
- **표현 이득 g_rep:** 편집 세트에서 '예측 오프셋 변화 / 가한 이동' 의 기울기 (1 = 표현이 이동을 정확히 따라감). 정책의 행동 이득(G_tt 0.10)과 **같은 편집 영상**으로 비교할 수 있다.

### 6. 판정 기준 (질문 6)
기준값 (A2–A3 측정에서 정함):
- 라벨 바닥 ≈ 0.3–0.43 cm
- 1–3 s 구간 tan SD 0.52–0.64 cm
- 사람 좌우 이동 설명력 R² 0.32–0.51 (라벨 자체가 행동과 맞는 정도)

| 판정 | 조건 (held-out fold, 1–3 s 구간, tan 기준) | 뜻 |
|---|---|---|
| 표현 정확 | MAE ≤ 0.45 cm (라벨 바닥 근처), R² ≥ 0.5, 편집 g_rep 0.7–1.3, 원시 픽셀 기준선보다 좋거나 같음, shuffle 보다 확실히 좋음 (CI 안 겹침) | 특징이 상대 위치를 선형으로 담고 있다 |
| 표현 부정확 | MAE ≥ 0.6 cm (≈ tan SD 수준 = 예측력 없음) 또는 R² ≤ 0.2 또는 g_rep ≤ 0.4 | 선형으로는 거의 못 꺼냄 |
| 그 사이 | 위 둘 다 아님 | 부분 표현 — 층·probe 종류별 비교로 판단 |

결합 판정 (정책 행동 이득 G_tt 0.10, exp2b 와 같은 편집 영상):
1. **'Vision 정확, Action 교정 약함':** expert 가 읽는 KV 층 중 하나라도 '표현 정확' (탁자 타깃 또는 roll 을 준 (d)) 이고, 정책 G_tt ≤ 0.3. → 병목은 action expert / 학습 신호 (교정 시연 부족, A3·참고 비교의 '마지막 3 s 정렬 적음' 과 일치하는지 확인).
2. **'VLM 에서 정보 손실':** SigLIP/projector 는 '표현 정확'인데, Gemma 뒤 층 KV 가 모두 '부정확'. → VLM 미세조정 후보.
3. **'Vision 부정확':** SigLIP 부터 '부정확'인데 원시 픽셀·마스크 기준선은 정확. → vision encoder 미세조정 / wrist 해상도·자르기 후보.
4. **'Roll 합성 부족':** (a)·(c) 정확, (b) 부정확, VLM 층에서도 (b) 개선 없음. → expert 가 state(roll) 와 합성해야 함. 데이터의 roll 분산, roll 표현 방식이 후보.

보조 확인 (1 번일 때만, GPU):
- pre 단계에서 action expert attention 질량이 wrist 큐브 토큰에 얼마나 가는지.
- expert 자신의 suffix hidden 에 대한 같은 probe. 담고 있는데 출력이 무시하면 '출력 읽기' 문제, 아예 안 담으면 '읽지 않음'.

### 7. 이후 학습 비교 계획 (질문 7, 실행은 승인 후)
**공통:**
- **데이터:** d2 에서 위치 hold-out 1묶음 (예: fold 3 test 69편 + 완충 52편 제외) 을 뺀 사본으로 학습한다 → 오프라인 지표를 보지 않은 위치에서 잴 수 있다.
  - 사본은 `lerobot-edit-dataset delete_episodes --new_root` 로 만든다 (원본 그대로 둠).
- **길이:** 같은 샘플 수, 10k 스텝 × bs32 (exp1 에서 10k ≈ 20k 지표). seed 1개, 상위 2개만 seed 2개.
- **오프라인 지표:**
  - exp1 grid (보정 K 끌림, 거리별 오차, hold-out 위치)
  - exp2 단계×카메라 이득 (wrist G_tt, front mid/pre)
  - exp4 seed 분산
  - 위 probe 를 새 모델의 (바뀐) KV 에 다시 적용 → 표현 vs 행동 변화를 같이 본다.
- **실물 (사용자 실행):** 위치 8곳 (K 4 + hold-out 4, 좌우 양쪽) × 큐브 각도 2 = 16판. 첫 잡기 성공, 최종 성공, 닫힘 순간 wrist 좌우 오차, 시간.

| 이름 | 학습 범위 | 데이터 | 언제 |
|---|---|---|---|
| R0 | expert only (현재 설정) | d2-holdout | 기준. 10k 재학습 (같은 조건 비교용) |
| R1 | expert only | d2-holdout + recovery | 판정 1 또는 4 |
| R2 | VLM 학습 (`train_expert_only=false`, `freeze_vision_encoder=true`) | d2-holdout | 판정 2 |
| R3 | R2 + recovery | d2-holdout + recovery | 판정 1·2 둘 다일 때 |
| R4 | full fine-tune (vision 포함) | d2-holdout | 판정 3 일 때만 |

- **Recovery 시연 (판정 1·4 일 때 수집):**
  - 파지 높이 위(약 5–8 cm)에서 일부러 좌우 ±1, ±2 cm, 앞뒤 ±1.5 cm 어긋난 자세로 시작해, 손목 영상을 보며 맞춘 뒤 잡는다.
  - 정책 실패 직후 이어서 사람이 교정하는 판도 포함한다.
  - K·Random 위치, roll 은 계획 각도대로. 규모 64–96편.
  - roll 영향을 따로 보려면 일부(32편)는 큐브 각도 0 으로.
- **자원 (추정, d4 끝난 뒤 짧은 시험 200 스텝으로 실측해서 확정):**
  - R0/R1: 10k ≈ 28 h (현 9.9 s/step).
