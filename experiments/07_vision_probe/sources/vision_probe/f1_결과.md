- front 32×24 픽셀로는 wrist 기준 상대 위치를 선형으로 못 읽는다 (R² < 0).

## 5. 판정 기준 (기준선으로 다시 맞춤, 특징 결과 전에 고정)

SigLIP · Gemma KV probe 의 test fold img→rot tan MAE 와 편집 이득 g_rep 으로 판정한다:

| 판정 | 조건 | 근거 |
|---|---|---|
| 표현 정확 | MAE ≤ 0.15 cm 그리고 g_rep(좌우) ≥ 0.7 | wrist RGB 0.085 와 state 0.297 의 사이에서 픽셀 쪽 |
| 표현 부분 | 0.15 < MAE < 0.30 또는 0.4 < g_rep < 0.7 | |
| 표현 부정확 | MAE ≥ 0.30 (관절값만큼도 못함) 또는 g_rep ≤ 0.4 | state 0.297 |

병목 위치 판정 (정책 행동 이득 G_tt 0.10 [0.02, 0.20], 같은 편집 방식):
- **Action Expert:** action expert 가 읽는 Gemma KV 층 중 하나라도 '표현 정확' 이면 → 정보는 expert 입력에 있는데 행동이 따라가지 않음.
- **VLM:** SigLIP 은 '정확'인데 Gemma 모든 층 KV 가 '부정확'.
- **Vision:** SigLIP 부터 '부정확' (wrist 픽셀 기준선은 0.085 로 정확하므로 영상 자체 정보는 있다).
- **roll 합성:** img 는 정확하고 tab(roll 없음)만 나쁜 것은 픽셀 기준선에서도 같다 (R² 0.43–0.60). 그래서 이것은 'roll 을 함께 써야 한다'는 성질이지 vision 결함이 아니다. Gemma 층에서 tab 이 img→rot 수준으로 오르는지를 따로 본다 (state 토큰과의 합성 여부).
