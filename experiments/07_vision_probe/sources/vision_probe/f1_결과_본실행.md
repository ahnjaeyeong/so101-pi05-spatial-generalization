## 3. 실행 중 고친 것 (결과에 영향)

1. **ridge 계산 가속** (`f1_probe.ridge_cv`): α 마다 풀던 것을 Gram 고유분해 한 번으로 바꿨다. wrist RGB 기준선으로 다시 계산해 선택 α 가 같고 MAE 가 소수점 끝까지 같음을 확인했다. 메모리 절약용 지연 로딩(`LazyRows`)과 청크 단위 투영도 같은 값임을 합성 자료로 확인했다 (차이 0.0).
2. **g_rep 의 roll 처리** (`f1_sensitivity.py`): 처음 버전은 roll 없이 탁자 좌표를 직접 예측하는 probe(tab, 정확도 R² 0.6)로 좌우 이득을 냈다. 판정 기준(`f1_결과.md` 5절)의 roll 보정 방식에 맞게 영상 축 probe 예측을 roll 로 회전한 값(`g_tan_img_rot`)을 주 지표로 하고, roll 없는 값(`g_tan_tab`)은 따로 기록했다.
3. **평가 롤아웃 라벨 조건**: 처음 계산에서 평가 프레임에는 train 의 `probe_ok` 조건(큐브 면적 ≥ 3,000 px, 영상 경계에 닿지 않음)이 빠져 있었다. 라벨 tan 이 최대 392 cm, px/cm 가 최소 5.7 까지 나와 MAE 5.5 cm 가 나왔다. 같은 조건을 적용했다 (`f1_results/eval_label_qc.csv`): 483 → 303 프레임. 그중 라벨이 train 범위 안(tan −2.20…1.46, rad −3.96…1.54 cm)인 것은 153 프레임이다.
4. **픽셀 기준선 g_rep 추가** (`f1_sens_baseline.py`): g_rep < 1 이 특징 탓인지, ridge 축소·편집 방식 탓인지 가르려고, 같은 편집 영상으로 wrist 마스크 · RGB 기준선의 g_rep 을 쟀다.
