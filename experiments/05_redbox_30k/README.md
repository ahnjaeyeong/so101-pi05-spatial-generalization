> d2 신규 20k 학습 (EXP-06) 과는 다른 실험이다. 이 실험은 **같은 redbox 384편 위에서 020000 체크포인트를 이어 학습**한 것이다.

## 목적·가설
- [관찰] 사용자 요청 "기존상태 그대로 10k 더".
- [가설] 학습량 부족이 공간 일반화 부족의 원인인가.

## 데이터셋
redbox_all 384편 (EXP-03 과 같음).

## 모델·학습 — `redbox_expert_bs32_resume30k`
| 항목 | 값 |
|---|---|
| 시작 | redbox 020000 (`--resume=true`: 가중치·옵티마이저·RNG·데이터 순서 이어감) |
| steps | 20,000 → 30,000 |
| LR | **2.5e-6 고정** (`--scheduler.num_decay_steps=20000`; 이 옵션이 없으면 LR 이 8.1e-6 으로 올라감) |
| batch / Vision freeze / Expert-only | 32 / 예 / 예 |
| loss | [사실] 20,050 step 0.023 → 30k 0.023; 1k 구간 평균 19–20k 0.0232 = 29–30k 0.0232 |
설정: [`configs/training/redbox_expert_bs32_resume30k/`](../../configs/training/redbox_expert_bs32_resume30k/).

## 추론 설정·평가 방법
EXP-04 공간 평가와 같은 study 설계·같은 시드 순서, 필터 B, RTC h20 EXP s5.

## 분석 결과
- [사실] loss 개선 없음 + 실물 첫 파지 하락 + 최종 동일.
- [가설] "학습량 부족" 가설은 이 데이터로 지지되지 않음.

## 한계 및 미확인
- [사실] **통제 안 된 차이**: 30k 시작 자세 pan +2.3…+3.3°, roll 84.4…85.4° vs 20k pan −2.4…−1.4°, roll 88.1…89.5°, 날짜 다름 (비교 보고서 미언급). 원인 미확인.
- 30k 오프라인 정확도 비교 없음, 5k–15k 실물 없음.
